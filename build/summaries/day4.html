Part 1. 소프트웨어

1-1. 소프트웨어의 분류

구분설명예
시스템 소프트웨어컴퓨터를 효율적으로 운영하기 위한 소프트웨어. 컴퓨터와 사용자 사이의 중계자 역할. 제어 프로그램 + 처리 프로그램운영체제(Windows, Linux, UNIX), 컴파일러, 어셈블러, 라이브러리
응용 소프트웨어운영체제의 도움을 받아 특정 작업을 수행하는 소프트웨어엑셀, 한글, 워드, 파워포인트, 포토샵, 한컴오피스
  • 운영체제 구성 복습: 제어 프로그램(감시, 작업 관리, 데이터 관리) / 처리 프로그램(언어 번역, 서비스, 문제 처리)
  • 함정: “운영체제의 도움을 받아 컴퓨터를 사용하게 해 주는 것”은 시스템 소프트웨어가 아니라 응용 소프트웨어 설명

1-2. 사용권에 따른 소프트웨어 분류 (꾸준히 출제)

종류핵심 키워드
상용 소프트웨어일정 금액을 지불하고 구입해서 사용
프리웨어누구나 무료로 사용하는 공개 소프트웨어
셰어웨어일정 기간 · 일부 기능 제한 상태로 무료 사용 후 구매 유도
애드웨어광고를 보는 대가로 무료 사용
데모 버전소프트웨어 홍보 목적으로 기능·기간을 제한해 무료 배포
알파 버전제작 회사 내부에서 테스트하기 위한 버전
베타 버전정식 출시 전 고객(일반 사용자)에게 미리 공개해 평가받는 버전
패치 버전이미 배포된 프로그램의 오류 수정·성능 향상을 위해 일부 파일을 변경 (예: 윈도우 업데이트)
번들하드웨어·소프트웨어를 구입할 때 끼워서 무료로 주는 프로그램
  • 암기: 알파 = 회사 안, 베타 = 고객 · 기출: “누구나 임의로 사용 = 프리웨어 / 기간·기능 제한 = 셰어웨어 / 구입 = 상용”

1-3. 유틸리티 · 압축 프로그램

  • 유틸리티: 컴퓨터를 더 쉽게 사용하도록 관리·유지·편의 기능을 돕는 보조 프로그램. Windows 제공 예: 파일 탐색기, 그림판, 계산기, 메모장
  • 함정: “유틸리티는 컴퓨터 동작에 필수적이다” ✗ (필수는 시스템 소프트웨어)
  • 압축 프로그램: 여러 파일을 하나로 묶고 용량을 줄여 전송 시간 절약·디스크 공간 효율화
  • 이미 압축한 파일을 다시 압축해도 계속 줄어들지는 않음
  • 압축 형식: ZIP, RAR, LZH, ARJ 등

1-4. 프로그래밍 언어: 저급 vs 고급

구분저급 언어고급 언어
형태기계어, 어셈블리어사람이 읽고 쓰기 쉬운 언어
특징컴퓨터가 직접 이해, 처리 속도 빠름, 사람이 이해하기 어려움컴파일러·인터프리터로 기계어로 번역해 실행, 활용 범위 넓음
예—Java, C, Python, BASIC, COBOL, FORTRAN, Pascal

1-5. 자주 나오는 고급 언어 3가지

언어핵심 특징
Java객체 지향, 운영체제·하드웨어에 독립적, 바이트 코드 생성 → 플랫폼에 상관없이 실행, 이식성 높음
C컴파일 방식, 구조적(절차적) 프로그래밍, 하드웨어 제어 가능, 빠르고 효율적인 시스템 언어
Python인터프리터 방식, 문법이 간단·직관적이라 초보자도 쉬움, 데이터 분석·인공지능·웹 개발, 플랫폼 독립적(Windows·Linux·UNIX·Mac), 객체 지향 (최근 단독 출제)
  • 함정: “파이썬은 절차 지향 언어” ✗ (객체 지향)

1-6. 언어 번역 프로그램: 컴파일러 vs 인터프리터

  • 원시 프로그램을 기계어 형태의 목적 프로그램으로 바꾸는 프로그램. 종류: 어셈블러, 컴파일러, 인터프리터
구분컴파일러인터프리터
번역 단위프로그램 전체한 줄씩
목적 프로그램생성됨 (가장 많이 출제)생성 안 됨
번역 속도느림빠름
실행 속도빠름느림
대표 언어CPython
  • 함정: “컴파일러는 번역 속도가 빠르다” ✗

1-7. 절차적 언어 vs 객체 지향 언어

구분절차적 언어객체 지향 언어
방식순서대로 위에서 아래로 실행 (요리 레시피)객체(물건) 단위로 각 객체가 스스로 동작
특징구조와 작업 절차 중시, 논리적 흐름대로 처리크고 복잡한 프로그램 구축이 어려운 절차적 언어의 문제점을 해결하려고 개발
대표 언어C, FORTRAN, BASIC, COBOLC++, Smalltalk, Java, Python
객체 지향 특징뜻쉬운 예
상속성기존 클래스 기능을 물려받아 재사용·확장자동차 기능을 전기차가 물려받음
추상화복잡한 것은 감추고 핵심만 표현엔진 구조를 몰라도 운전 가능
캡슐화데이터와 기능을 묶고 외부 접근 제한리모컨 버튼만 누르고 내부 회로는 못 건드림
다형성같은 명령이 객체에 따라 다르게 동작“달린다” → 자동차는 바퀴, 사람은 발
오버로딩이름은 같지만 매개변수가 다른 메서드 여러 개 정의“연다” → 차 문 열기, 창문 열기
  • 요약: 상속으로 재사용, 추상화로 단순화, 캡슐화로 보호, 다형성으로 유연하게

1-8. 웹 프로그래밍 언어 (키워드로 찾기)

언어키워드
HTML웹 페이지를 만드는 기본 언어 (텍스트·이미지·하이퍼링크)
HTML5차세대 웹 표준, 비디오·오디오 등 멀티미디어 기능 추가, ActiveX 없이 멀티미디어 재생
DHTMLDynamic. HTML 단점 보완, 애니메이션 지원, 사용자 상호작용에 따른 동적인 웹 페이지
XML데이터 교환용. HTML과 SGML의 장점 결합, 사용자가 태그를 직접 정의
SGMLXML의 기반 언어. 문서를 저장·전송·자동 처리
VRML3차원 가상 공간 표현
WML무선 접속 기기(PDA·휴대폰)에서 텍스트·이미지 표시

JSPJava 기반 서버 측 언어, 운영체제에 상관없이 실행

1-9. Part 1 시험 포인트

  • 운영체제의 도움을 받는 것 = 응용 소프트웨어, 유틸리티는 필수 아님
  • 알파 = 회사 내부, 베타 = 고객, 패치 = 오류 수정·업데이트, 셰어웨어 = 기간·기능 제한
  • Java 이식성·객체 지향, C 컴파일·하드웨어 제어, Python 인터프리터·객체 지향
  • 컴파일러 = 전체 번역·목적 프로그램 생성·실행 빠름
  • HTML5 = ActiveX 없이 멀티미디어, DHTML = 동적, XML = 태그 직접 정의

Part 2. 멀티미디어

2-1. 멀티미디어의 4가지 특징

특징뜻
통합성텍스트·그림·소리·영상 등 여러 매체를 하나로 통합
비선형성처음부터 끝까지 순서대로가 아니라 원하는 부분을 자유롭게 선택
쌍방향성사용자와 컴퓨터가 서로 주고받음 (상호작용)
디지털화모든 정보를 0과 1로 저장, 복사해도 원본 그대로 유지
  • 함정: “파일 형식이 획일화되어 제작이 쉬워진다” ✗ (선형성 설명. 멀티미디어는 비선형)

2-2. 멀티미디어 활용 분야

용어설명
VOD주문형 비디오. 원하는 시간에 영화·드라마를 실시간 전송받아 시청
MOD주문형 음악. 모바일 인터넷으로 음원을 스트리밍해 실시간 청취 (멜론·지니 등)
VCS화상 회의 시스템. 떨어진 곳에서 비디오·오디오로 회의
CAI컴퓨터 보조 교육. 컴퓨터를 수업 매체로 활용
PACS의료 영상 정보 시스템. X-ray·CT 등 의료 영상을 디지털로 저장·전송
VDT 증후군장시간 컴퓨터 사용으로 생기는 신체적·정신적 장애
PDA스마트폰 이전의 휴대용 개인 정보 단말기

2-3. 멀티미디어 관련 기술

기술핵심 키워드
VR (가상 현실)컴퓨터 그래픽·시뮬레이션으로 가상 세계를 현실처럼 체험 (3차원)
AR (증강 현실)실제 화면에 가상의 3차원 정보를 실시간으로 겹쳐 보여 줌
홀로그램빛의 간섭 현상으로 입체 정보를 기록·재생
키오스크무인 정보 안내·주문 시스템 (터치스크린)
디지털 워터마킹사진·동영상 등 디지털 데이터에 저작권 정보를 비밀리에 삽입해 관리 (최근 출제)
  • 함정: “가상 현실은 2차원 그래픽” ✗ (3차원)

2-4. 비트맵 vs 벡터 (계속 출제)

구분비트맵 (래스터)벡터
표현점(픽셀)점과 점을 잇는 직선·곡선
확대 시계단 현상으로 깨짐깨지지 않고 선명
용량큼 (색상 정보가 많을수록 증가)작음
표시 속도빠름느림
용도사진처럼 사실적인 이미지로고·아이콘 등 단순한 그래픽 (일러스트레이터)
형식BMP, GIF, JPG, PNGAI, WMF

2-5. 그래픽 관련 용어 (모두 중요)

용어뜻
모델링대상을 3차원 형태로 만드는 것 (캐릭터의 3D 몸체 만들기)
렌더링3D 이미지에 명암·색상·질감을 입혀 사실감 있게 표현 (피부색·조명·그림자). 모델링 다음 단계
디더링제한된 색을 조합해 더 다양한 색감·음영 표현
모핑한 이미지가 다른 이미지로 서서히 변하는 효과
인터레이싱그래픽: 윤곽부터 점점 선명하게 표시 / 영상: 화면 줄을 번갈아 표시
메조틴트수많은 점과 선으로 거칠고 빈티지한 질감 표현
앨리어싱저해상도에서 경계가 계단처럼 깨져 보이는 현상
안티앨리어싱경계 픽셀 색을 혼합해 부드럽게 처리 → 계단 현상 최소화
리터칭이미지·사진 일부를 수정·보정 (잡티 제거, 색 조정)
블러링초점이 안 맞은 것처럼 흐릿하게 처리
  • 함정: “모델링은 명암·색상·질감을 넣어 사실감을 더하는 것” ✗ (렌더링)
  • 애니메이션 기법: 셀(셀로판에 옮겨 채색), 키프레임, 클레이(점토)

2-6. 그래픽 파일 형식

형식방식 / 압축특징
GIF비트맵 / 무손실256색, 투명 배경 + 애니메이션 가능
JPG비트맵 / 손실·무손실 모두압축률 높아 인터넷 정지 이미지·사진에 적합
PNG비트맵 / 무손실GIF를 대체하려고 개발, 투명 배경 가능, 애니메이션 불가
BMP · WMF비트맵 / 벡터Windows 기본 형식
  • 함정: “GIF는 손실·무손실 압축 모두 지원” ✗ (JPG)

2-7. 사운드 파일 형식

형식특징
WAV아날로그 소리를 디지털화, 소리의 파형을 그대로 저장. 음질 좋지만 용량 큼, 녹음 조건에 따라 크기 가변, Windows Media Player로 재생
MIDI전자 악기 간 연주 정보를 전송하는 규격. 음 높이·길이·세기·악기 종류를 기호화해 저장 → 용량 매우 작음
MP3MPEG 기반 고압축, 용량 작고 음질 좋음, 대표 오디오 형식
  • 함정: “WAV는 음높이·음길이 등 음악 기호가 정의되어 있다” ✗ (MIDI)

2-8. 동영상 파일 형식 · MPEG 규격

  • 동영상 형식: MPG(MPEG), ASF, AVI(Windows 표준), MOV, DivX — JPG·GIF·BMP는 그림 형식이므로 구별
  • MPEG: 동영상과 오디오 모두 압축, 손실 압축으로 중복 데이터 제거, 비대칭 압축(압축은 복잡, 재생은 빠름)
  • DivX: MPEG-4와 MP3를 재조합한 코덱, 수 GB의 DVD를 CD 1~2장 분량으로 줄이는 고화질 동영상 형식
MPEG 규격키워드
MPEG-1비디오 CD 수준 화질

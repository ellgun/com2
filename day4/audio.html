컴퓨터 활용능력 2급 필기 4일차 음성 강의입니다. 오늘은 컴퓨터 일반 과목에서 소프트웨어와 프로그래밍 언어, 웹 언어, 그리고 멀티미디어를 살펴보겠습니다.

먼저 소프트웨어의 분류입니다. 소프트웨어는 시스템 소프트웨어와 응용 소프트웨어로 나뉩니다. 시스템 소프트웨어는 컴퓨터를 효율적으로 운영하기 위한 소프트웨어로, 컴퓨터와 사용자 사이에서 중계자 역할을 합니다. 운영체제, 컴파일러, 어셈블러, 라이브러리가 여기에 속합니다. 운영체제는 제어 프로그램과 처리 프로그램으로 구성됩니다. 제어 프로그램에는 감시, 작업 관리, 데이터 관리 프로그램이 있고, 처리 프로그램에는 언어 번역, 서비스, 문제 처리 프로그램이 있습니다.

응용 소프트웨어는 운영체제의 도움을 받아 특정 작업을 하는 소프트웨어입니다. 엑셀, 한글, 워드, 파워포인트, 포토샵, 한컴오피스가 모두 응용 소프트웨어입니다. 윈도우, 리눅스, 유닉스는 운영체제이므로 시스템 소프트웨어입니다. 운영체제의 도움을 받아 컴퓨터를 사용하게 해 준다는 설명이 시스템 소프트웨어 문제에 나오면 틀린 보기입니다. 그것은 응용 소프트웨어 설명입니다.

다음은 사용권에 따른 소프트웨어 분류입니다. 꾸준히 출제되니 키워드를 꼭 외우세요. 상용 소프트웨어는 돈을 내고 구입해서 쓰는 것입니다. 프리웨어는 누구나 무료로 쓰는 공개 소프트웨어입니다. 셰어웨어는 일정 기간 동안, 일부 기능을 제한한 상태로 무료로 쓰게 하고 나중에 구매를 유도하는 프로그램입니다. 애드웨어는 광고를 보는 대가로 무료로 쓰는 것입니다. 데모 버전은 홍보를 위해 기능이나 기간을 제한해서 무료로 배포하는 것입니다.

알파 버전과 베타 버전은 헷갈리게 출제됩니다. 둘 다 테스트 목적이지만, 알파 버전은 제작 회사 안에서 테스트하는 버전이고, 베타 버전은 정식 출시 전에 고객에게 미리 공개해서 평가를 받는 버전입니다. 알파는 회사, 베타는 고객. 이렇게 외우세요. 패치 버전은 이미 배포된 프로그램의 오류를 고치거나 성능을 높이기 위해 일부 파일을 바꿔 주는 것입니다. 윈도우 업데이트가 대표적인 예입니다. 번들은 하드웨어나 소프트웨어를 살 때 끼워서 무료로 주는 프로그램입니다.

유틸리티 프로그램은 컴퓨터를 더 쉽게 쓸 수 있도록 관리와 유지, 편의 기능을 돕는 보조 프로그램입니다. 윈도우가 제공하는 유틸리티에는 파일 탐색기, 그림판, 계산기, 메모장이 있습니다. 유틸리티는 컴퓨터 동작에 꼭 필요한 필수 프로그램이 아닙니다. 유틸리티가 필수적이라는 보기는 틀린 내용입니다.

압축 프로그램은 여러 파일을 하나로 묶고 용량을 줄여서, 전송 시간을 아끼고 디스크 공간을 효율적으로 쓰게 해 줍니다. 압축 형식에는 집, 알에이알, 엘제트에이치, 에이알제이가 있습니다. 이미 압축한 파일을 다시 압축한다고 해서 용량이 계속 줄어들지는 않습니다.

이제 프로그래밍 언어입니다. 프로그래밍 언어는 저급 언어와 고급 언어로 나뉩니다. 저급 언어는 기계어와 어셈블리어로, 컴퓨터가 직접 이해할 수 있어서 처리 속도는 빠르지만 사람이 이해하기 어렵습니다. 고급 언어는 사람이 읽고 쓰기 쉬운 언어이고, 컴파일러나 인터프리터를 통해 기계어로 번역해서 실행합니다. 고급 언어에는 자바, 씨 언어, 파이썬, 베이직, 코볼, 포트란, 파스칼이 있습니다.

이 중에서 자바, 씨 언어, 파이썬의 특징을 꼭 알아 두세요. 자바는 객체 지향 언어이고, 운영체제와 하드웨어에 독립적입니다. 바이트 코드를 만들어서 플랫폼에 상관없이 실행되므로 이식성이 높습니다. 한 번 만들면 윈도우든 안드로이드든 어디서나 실행할 수 있다는 뜻입니다.

씨 언어는 컴파일 방식의 언어이고, 구조적 프로그래밍이 가능합니다. 하드웨어를 제어할 수 있고, 빠르고 효율적인 시스템 언어입니다. 구조적 프로그래밍과 하드웨어 제어라는 말이 나오면 씨 언어를 고르세요.

파이썬은 최근에 단독으로 자주 출제됩니다. 파이썬은 인터프리터 방식의 언어입니다. 문법이 간단하고 직관적이라 초보자도 배우기 쉽습니다. 데이터 분석, 인공지능, 웹 개발 등 다양한 분야에서 쓰이고, 플랫폼에 독립적이라 윈도우, 리눅스, 유닉스, 맥에서 모두 실행됩니다. 파이썬은 객체 지향 언어입니다. 파이썬이 절차 지향 언어라는 보기는 틀린 내용입니다.

언어 번역 프로그램은 사람이 작성한 원시 프로그램을 컴퓨터가 이해하는 목적 프로그램으로 바꿔 주는 프로그램입니다. 어셈블러, 컴파일러, 인터프리터가 있습니다. 컴파일러와 인터프리터의 차이를 알아야 합니다. 컴파일러는 프로그램 전체를 한꺼번에 번역하고, 인터프리터는 한 줄씩 번역합니다. 컴파일러는 목적 프로그램을 만들고, 인터프리터는 만들지 않습니다. 목적 프로그램이 생기는지를 묻는 문제가 가장 많습니다. 컴파일러는 전체를 번역하니까 번역 속도는 느리지만 실행 속도는 빠릅니다. 인터프리터는 번역 속도는 빠르지만 실행 속도는 느립니다. 컴파일러의 대표 언어는 씨 언어, 인터프리터의 대표 언어는 파이썬입니다. 컴파일러가 번역 속도가 빠르다는 보기는 틀린 내용입니다.

다음은 절차적 언어와 객체 지향 언어입니다. 절차적 언어는 요리 레시피처럼 위에서 아래로 순서대로 실행하는 언어입니다. 구조와 작업 절차를 중요하게 여기고, 논리적인 흐름대로 처리합니다. 씨 언어, 포트란, 베이직, 코볼이 여기에 속합니다.

객체 지향 언어는 크고 복잡한 프로그램을 만들기 어려운 절차적 언어의 문제점을 해결하려고 개발되었습니다. 물건, 즉 객체 단위로 일하는 언어입니다. 자동차를 예로 들면, 절차적 언어는 시동을 켜고, 기어를 넣고, 액셀을 밟는 순서를 코딩하지만, 객체 지향 언어는 자동차라는 객체 안에 엔진과 기어와 액셀을 넣어 두고, 시동이라는 명령을 주면 각 부분이 알아서 동작하게 합니다. 객체 지향 언어에는 씨 플러스 플러스, 스몰토크, 자바, 파이썬이 있습니다.

객체 지향 언어의 특징도 자주 나옵니다. 상속성은 부모의 능력을 자식이 물려받는 것입니다. 기존 클래스의 기능을 물려받아 재사용하고 확장합니다. 자동차의 기능을 전기차가 물려받는 것과 같습니다. 추상화는 복잡한 것은 감추고 핵심만 보여 주는 것입니다. 엔진 구조를 몰라도 운전할 수 있는 것과 같습니다. 캡슐화는 데이터와 기능을 하나로 묶어서 외부에서 함부로 바꾸지 못하게 보호하는 것입니다. 리모컨 버튼만 누르고 내부 회로는 건드리지 못하는 것과 같습니다. 다형성은 같은 명령이라도 객체에 따라 다르게 동작하는 것입니다. 달린다는 같은 명령에 자동차는 바퀴로, 사람은 발로 달립니다. 오버로딩은 이름은 같지만 매개변수가 다른 여러 메서드를 만들어 상황에 맞게 쓰는 것입니다. 정리하면, 상속으로 재사용하고, 추상화로 단순하게 하고, 캡슐화로 보호하고, 다형성으로 유연하게 동작합니다.

이제 웹 프로그래밍 언어입니다. 키워드로 찾으면 됩니다. HTML은 웹 페이지를 만드는 기본 언어입니다. HTML 5는 차세대 웹 표준으로, 비디오와 오디오 같은 멀티미디어 기능이 추가되었고, 액티브 엑스 없이도 멀티미디어를 재생할 수 있습니다. 액티브 엑스 없이라는 말이 나오면 HTML 5입니다. DHTML의 D는 다이나믹입니다. HTML의 단점을 보완해서 애니메이션을 지원하고, 사용자 상호작용에 따라 바뀌는 동적인 웹 페이지를 만듭니다. 동적이라는 말이 나오면 DHTML입니다. XML은 데이터 교환용 언어로, HTML과 SGML의 장점을 합쳤고, 사용자가 태그를 직접 정의할 수 있습니다. 태그를 정의한다는 말이 나오면 XML입니다. SGML은 XML의 기반이 된 언어로, 문서를 저장하고 전송하고 자동 처리합니다. VRML은 3차원 가상 공간을 표현하는 언어입니다. WML은 PDA나 휴대폰 같은 무선 접속 기기에서 텍스트와 이미지를 보여 주는 언어입니다. ASP는 윈도우 환경의 서버 측 스크립트 언어이고, JSP는 자바 기반의 서버 측 언어로 운영체제에 상관없이 실행됩니다.

이제 두 번째 부분, 멀티미디어입니다. 멀티미디어에는 네 가지 특징이 있습니다. 통합성은 글, 그림, 소리, 영상 같은 여러 매체를 하나로 합치는 것입니다. 비선형성은 처음부터 끝까지 순서대로 보지 않고, 원하는 부분을 자유롭게 골라서 보는 것입니다. 쌍방향성은 사용자와 컴퓨터가 서로 주고받는 것입니다. 클릭하면 바로 반응하는 것이 그 예입니다. 디지털화는 모든 정보를 0과 1로 저장해서, 복사해도 원본 그대로 유지되는 것입니다. 파일 형식이 획일화되어 제작이 쉬워진다는 보기는 틀린 내용입니다. 그것은 선형성에 가까운 설명이고, 멀티미디어는 비선형입니다.

멀티미디어 활용 분야입니다. VOD는 주문형 비디오로, 원하는 시간에 영화나 드라마를 실시간으로 받아서 보는 서비스입니다. MOD는 주문형 음악으로, 모바일 인터넷으로 음원을 스트리밍해서 실시간으로 듣는 서비스입니다. 멜론이나 지니 같은 서비스가 여기에 해당합니다. VCS는 화상 회의 시스템이고, CAI는 컴퓨터를 수업 매체로 쓰는 컴퓨터 보조 교육입니다. PACS는 의료 영상을 디지털로 저장하고 전송하는 의료 영상 정보 시스템입니다. VDT 증후군은 컴퓨터를 오래 써서 생기는 신체적, 정신적 장애입니다. PDA는 스마트폰 이전의 휴대용 개인 정보 단말기입니다.

멀티미디어 관련 기술입니다. VR, 가상 현실은 컴퓨터 그래픽과 시뮬레이션으로 가상 세계를 현실처럼 체험하는 기술이고, 3차원입니다. 가상 현실이 2차원 그래픽이라는 보기는 틀린 내용입니다. AR, 증강 현실은 실제 화면 위에 가상의 3차원 정보를 실시간으로 겹쳐서 보여 주는 기술입니다. 체험하면 VR, 겹치면 AR입니다. 홀로그램은 빛의 간섭 현상으로 입체 정보를 기록하고 재생합니다. 키오스크는 무인 안내와 주문 시스템입니다. 디지털 워터마킹은 최근에 출제되었습니다. 사진이나 동영상 같은 디지털 데이터에 저작권 정보를 비밀리에 넣어 관리하는 기술입니다.

다음은 비트맵과 벡터입니다. 아직도 계속 출제됩니다. 비트맵은 래스터 방식이라고도 하며, 점, 즉 픽셀로 이미지를 표현합니다. 확대하면 계단 현상이 생겨서 깨져 보입니다. 용량이 크고, 색상 정보가 많을수록 커집니다. 표시 속도는 빠르고, 사진처럼 사실적인 이미지에 알맞습니다. 벡터는 점과 점을 잇는 직선과 곡선으로 이미지를 표현합니다. 확대해도 깨지지 않고 선명하며, 용량이 작습니다. 표시 속도는 느리고, 로고나 아이콘 같은 단순한 그래픽에 씁니다. 일러스트레이터가 벡터 방식입니다. 직선과 곡선으로 표현한다는 설명이 비트맵 문제에 나오면 틀린 보기입니다.

그래픽 관련 용어는 모두 중요합니다. 특히 모델링과 렌더링을 헷갈리지 마세요. 모델링은 대상을 3차원 형태로 만드는 것입니다. 영화 캐릭터의 3D 몸체를 만드는 단계입니다. 렌더링은 그렇게 만든 3차원 이미지에 명암, 색상, 질감을 입혀서 사실감 있게 표현하는 것입니다. 피부색이나 조명, 그림자를 입히는 단계입니다. 모델링을 먼저 하고 렌더링을 합니다. 모델링이 명암과 색상과 질감을 넣는다는 보기는 틀린 내용입니다. 그것은 렌더링입니다.

디더링은 제한된 색을 조합해서 더 다양한 색감과 음영을 표현하는 기법입니다. 모핑은 한 이미지가 다른 이미지로 서서히 바뀌는 효과입니다. 아빠 얼굴이 아들 얼굴로 서서히 변하는 것을 떠올리세요. 인터레이싱은 그래픽에서는 윤곽부터 보여 주고 점점 선명하게 표시하는 기법이고, 영상에서는 화면의 줄을 번갈아 표시하는 기술입니다. 메조틴트는 수많은 점과 선으로 거칠고 빈티지한 질감을 표현합니다. 앨리어싱은 해상도가 낮을 때 경계가 계단처럼 깨져 보이는 현상이고, 안티앨리어싱은 경계 픽셀의 색을 섞어서 부드럽게 보이게 해, 계단 현상을 줄이는 기법입니다. 리터칭은 사진의 일부를 수정하거나 보정하는 것이고, 블러링은 초점이 안 맞은 것처럼 흐릿하게 처리하는 것입니다. 애니메이션 기법에는 셀로판에 옮겨 채색하는 셀 애니메이션, 키프레임 애니메이션, 점토를 쓰는 클레이 애니메이션이 있습니다.

이제 파일 형식입니다. 그래픽 파일 중에서 GIF, JPG, PNG가 자주 나옵니다. GIF는 비트맵 방식이고 무손실 압축입니다. 256색까지 표현하고, 배경을 투명하게 할 수 있고, 애니메이션도 됩니다. JPG는 비트맵 방식이고 손실 압축과 무손실 압축을 모두 지원합니다. 압축률이 높아서 인터넷의 정지 이미지나 사진에 알맞습니다. PNG는 GIF를 대체하려고 만든 비트맵 형식으로, 무손실 압축이고, 배경을 투명하게 할 수 있지만 애니메이션은 안 됩니다. GIF는 투명과 애니메이션 모두, PNG는 투명만. 이 차이를 기억하세요. GIF가 손실과 무손실 압축을 모두 지원한다는 보기는 틀린 내용입니다. 그것은 JPG입니다.

사운드 파일 형식입니다. WAV는 아날로그 소리를 디지털로 바꾼 것으로, 소리의 파형을 그대로 저장합니다. 음질은 좋지만 용량이 크고, 녹음 조건에 따라 파일 크기가 달라집니다. 윈도우 미디어 플레이어로 재생할 수 있습니다. MIDI는 전자 악기 사이의 연주 정보를 전송하는 규격입니다. 음 높이, 음 길이, 세기, 악기 종류 같은 정보를 기호로 바꿔 저장하므로 용량이 아주 작습니다. 음악 기호가 정의되어 있다는 말이 나오면 MIDI입니다. MP3는 압축률이 높아 용량이 작으면서 음질이 좋은 대표적인 오디오 형식입니다.

동영상 파일 형식에는 MPEG, ASF, AVI, MOV, DivX가 있습니다. 윈도우의 표준 동영상 형식은 AVI입니다. JPG, GIF, BMP는 그림 형식이므로 동영상 형식을 고르는 문제에서 구별해야 합니다. MPEG은 동영상과 오디오를 모두 압축하고, 손실 압축으로 중복 데이터를 없애서 압축 효율이 뛰어납니다. DivX는 MPEG 4와 MP3를 조합한 코덱으로, 몇 기가바이트의 DVD를 CD 한두 장 분량으로 줄이는 고화질 동영상 형식입니다.

MPEG 규격도 꾸준히 출제됩니다. 특히 4, 7, 21번을 외우세요. MPEG 1은 비디오 CD 수준의 화질이고, MPEG 2는 DVD와 HDTV, 위성 방송에 씁니다. MPEG 4는 인터넷과 무선 통신용으로, 복합 멀티미디어 서비스의 통합 표준입니다. MPEG 7은 멀티미디어 데이터를 검색하는 규격으로, 디지털 방송, 전자도서관, 전자상거래에 활용됩니다. MPEG 21은 디지털 콘텐츠의 제작, 유통, 보안 등 전체 과정을 관리합니다. 통합 표준은 4, 검색은 7, 제작과 유통과 보안은 21입니다.

마지막으로 기타 멀티미디어 용어입니다. 코덱은 아날로그와 디지털 신호를 서로 바꿔 주는 장치입니다. 스트리밍은 다운로드 없이 실시간으로 재생하는 기술입니다. 다이렉트 엑스는 게임과 영상 같은 고성능 멀티미디어 처리를 지원하는 마이크로소프트의 API입니다. HCI는 사람과 컴퓨터 사이의 자연스러운 상호작용 기술입니다. 데이터 글러브는 손의 움직임을 입력하는 장갑, HMD는 머리에 쓰는 입체 디스플레이, 구글 글래스는 안경형 웨어러블 기기입니다. 하이퍼링크는 문서와 문서를 연결하는 기능이고, IPTV는 인터넷망으로 실시간 방송과 VOD를 제공하는 서비스입니다.

오디오 관련 용어로 샘플링은 소리를 일정 간격으로 측정해서 숫자로 바꾸는 과정이고, PCM은 아날로그를 디지털로 바꾸는 대표적인 오디오 기술이고, 시퀀싱은 미디 음악을 편집하고 제작하는 과정입니다. 오디오 용어가 아닌 것을 고르라는 문제에는 인터레이싱이 답으로 나왔습니다. 모바일 멀티미디어 커뮤니케이션에는 모바일 화상전화, 위치 기반 서비스인 LBS, 사진과 동영상과 음성을 보내는 MMS가 있습니다. 디지털 멀티미디어 방송인 DMB는 여기에 해당하지 않는다는 문제가 출제되었습니다.

정리하겠습니다. 운영체제의 도움을 받는 것은 응용 소프트웨어이고, 유틸리티는 필수가 아닙니다. 알파는 회사, 베타는 고객, 패치는 오류 수정입니다. 자바는 이식성, 씨 언어는 컴파일과 하드웨어 제어, 파이썬은 인터프리터입니다. 컴파일러는 전체를 번역하고 목적 프로그램을 만듭니다. HTML 5는 액티브 엑스 없이, DHTML은 동적, XML은 태그 정의입니다. 멀티미디어 특징은 통합성, 비선형성, 쌍방향성, 디지털화입니다. 비트맵은 점이라 확대하면 깨지고, 벡터는 선이라 깨지지 않습니다. 모델링 다음이 렌더링, 계단 현상을 없애는 것은 안티앨리어싱입니다. GIF는 투명과 애니메이션, PNG는 투명만, JPG는 손실과 무손실 모두입니다. MPEG 4는 통합 표준, 7은 검색, 21은 제작과 유통과 보안입니다. 오늘 강의는 여기까지입니다. 수고하셨습니다.

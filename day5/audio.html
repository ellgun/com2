음성 원고 보기

컴퓨터 활용능력 2급 필기 5일차 음성 강의입니다. 오늘은 컴퓨터 일반 과목의 마지막 부분으로, 네트워크와 인터넷, 그리고 바이러스와 정보 보안을 살펴보겠습니다. 용어가 많고 암기할 내용이 많으니 핵심 키워드 위주로 들어 주세요.

먼저 네트워크 운영 방식입니다. 중앙 집중 방식은 모든 데이터 처리와 관리를 하나의 중앙 컴퓨터가 담당하는 방식입니다. 피어 투 피어 방식은 동배간 처리 방식이라고도 하며, 모든 컴퓨터가 서버이자 클라이언트 역할을 합니다. 서버 없이도 자원을 공유할 수 있고 소규모 네트워크에 알맞습니다. 메신저로 친구와 직접 파일을 주고받는 것을 떠올리세요. 클라이언트 서버 방식은 요청하는 클라이언트와 제공하는 서버의 역할이 명확히 나뉜 방식입니다. 식당의 손님과 주방처럼 생각하면 됩니다. 분산 처리에 적합하고 보안 관리가 쉽지만, 서버 구축과 유지 비용이 들고 서버에 장애가 생기면 서비스가 멈출 수 있습니다. 분산 처리 환경에 가장 알맞은 방식을 묻는 문제의 답은 클라이언트 서버 방식입니다.

통신망의 종류입니다. 랜은 근거리 통신망으로 건물이나 회사 같은 좁은 지역을 연결합니다. 맨은 도시권 통신망, 웬은 국가나 대륙을 연결하는 광역 통신망입니다. 크기는 웬, 맨, 랜 순서입니다. 밴, 부가가치 통신망은 기본 통신 회선에 정보 서비스를 더한 통신망입니다. 카드 결제를 카드사와 연결해 주는 중계망이 그 예입니다. ISDN, 종합정보통신망은 전화와 팩스와 데이터를 하나의 회선으로 통합해서 보냅니다. 하나의 회선이라는 말이 나오면 ISDN입니다. B-ISDN은 광대역 종합정보통신망으로 ISDN보다 빠른 고속 디지털 방식입니다. B-ISDN이 아날로그 방식이라는 보기는 틀린 내용입니다.

최근에 출제된 내용으로, 무선 랜을 구성하는 요소는 단말기, 브리지, 랜카드, 안테나, 그리고 액세스 포인트, 즉 AP입니다. 리피터는 무선 랜 구성 요소가 아닙니다.

통신 방식도 알아 두세요. 단방향은 한쪽으로만 보내는 방식입니다. 반이중은 양쪽으로 보낼 수 있지만 동시에는 안 되는 방식으로, 무전기가 대표적입니다. 전이중은 양쪽이 동시에 주고받을 수 있는 방식으로, 전화가 대표적입니다.

네트워크 구성 형태는 그림으로도 나옵니다. 성형, 또는 스타형은 중앙의 허브나 스위치에 각 컴퓨터가 연결된 별 모양입니다. 설치와 확장이 쉽지만, 중앙 장치가 고장 나면 전체가 마비됩니다. 중앙 컴퓨터에 이상이 생기면 전체 기능이 마비되는 형태를 묻는 문제의 답은 성형입니다. 트리형은 성형을 여러 계층으로 확장한 나뭇가지 모양입니다. 링형은 원 모양으로 데이터가 한 방향으로 돌고, 한 곳이 고장 나면 전체에 영향을 줍니다. 버스형은 하나의 공통 케이블에 여러 장치를 연결한 형태로, 설치가 간단하고 비용이 적지만 충돌이 잦고, 기밀성이 낮으며 회선 길이에 제한이 있습니다. 버스형이 기밀 보장이 우수하다는 보기는 틀린 내용입니다. 망형, 또는 메시형은 모든 노드가 서로 직접 연결되어 있어서, 장애가 생겨도 우회 경로로 통신할 수 있습니다. 신뢰성이 가장 높지만 설치 비용이 많이 들고 관리가 복잡합니다.

다음은 OSI 7계층입니다. 국제 표준화 기구 ISO가 만든 네트워크 통신 규약입니다. 순서는 물리, 데이터 링크, 네트워크, 전송, 세션, 표현, 응용입니다. 특히 2, 3, 4계층이 자주 나옵니다. 1계층 물리 계층은 전송 매체의 전기적, 물리적 특성을 규정하고, 장비는 리피터와 허브입니다. 2계층 데이터 링크 계층은 오류를 검출하고 프레임 단위로 전송하며, 장비는 브리지와 스위치입니다. 3계층 네트워크 계층은 경로를 설정하며, 장비는 라우터입니다. 4계층 전송 계층은 신뢰성 있는 전송과 오류 복구를 담당하며, 장비는 게이트웨이입니다. 물리는 리피터, 데이터 링크는 브리지, 네트워크는 라우터, 전송은 게이트웨이. 이렇게 짝지어 외우세요. 세 번째 계층이 데이터 링크라는 보기는 틀린 내용입니다. 3계층은 네트워크입니다.

네트워크 장비는 키워드로 찾으면 됩니다. 라우터는 IP 주소를 기준으로 최적의 경로를 찾아 줍니다. 리피터는 신호를 증폭해서 멀리 보내 줍니다. 브리지는 다리라는 뜻처럼, 같은 프로토콜을 쓰는 랜과 랜을 연결합니다. 게이트웨이는 문이라는 뜻처럼, 다른 네트워크로 들어가는 출입구 역할을 합니다. 허브는 여러 컴퓨터를 연결하는 장비이고, DNS는 도메인 이름과 IP 주소를 서로 바꿔 줍니다. 모뎀은 디지털 신호와 아날로그 신호를 서로 바꿔 줍니다. 브리지가 디지털을 아날로그로 바꾼다는 보기는 틀린 내용입니다. 그것은 모뎀입니다.

네트워크 명령어는 명령 프롬프트에서 입력합니다. ipconfig는 내 IP 주소와 서브넷 마스크, 기본 게이트웨이를 보여 줍니다. tracert는 목적지 서버까지의 경로를 추적합니다. ping은 상대 IP나 도메인에 접속할 수 있는지, 왕복 시간이 얼마인지 확인합니다.

이제 프로토콜입니다. 프로토콜은 서로 다른 컴퓨터가 통신하기 위해 약속한 규칙입니다. TCP는 데이터를 패킷으로 나눠 보내고 흐름과 오류를 제어하는 전송 계층 프로토콜이고, IP는 주소를 지정하고 경로를 찾는 네트워크 계층 프로토콜입니다. 인터넷의 기본 규약은 TCP IP입니다. HTTP는 웹 서버와 브라우저 사이에서 하이퍼텍스트 문서를 주고받습니다. DHCP는 IP 주소를 자동으로, 동적으로 할당해 줍니다. IP 자동 할당이라는 말이 나오면 DHCP입니다. FTP는 파일을 업로드하고 다운로드하는 원격 파일 전송 프로토콜입니다. FTP를 쓰려면 계정이 필요하고, 업로드, 다운로드, 삭제, 이름 변경이 가능합니다. 하지만 FTP 서버에 있는 프로그램을 그 자리에서 바로 실행할 수는 없고, 내려받은 뒤 실행해야 합니다. 이것을 묻는 문제가 많습니다. ARP는 IP 주소로 실제 물리 주소인 맥 주소를 찾아 줍니다. ICMP는 네트워크 상태를 점검하고 오류를 알려 주며, ping 명령에서 쓰입니다. SNMP는 라우터나 스위치 같은 네트워크 장비를 관리합니다. WAP은 무선 인터넷 규약이고, 텔넷은 원격으로 다른 컴퓨터에 접속하는 프로토콜입니다.

전자우편 프로토콜 네 가지는 모두 중요합니다. SMTP는 메일을 보낼 때, POP3는 메일을 받을 때 씁니다. MIME은 이미지, 오디오, 영상, 첨부 파일 같은 멀티미디어 메일을 보낼 수 있게 해 줍니다. IMAP은 메일을 서버에 남겨 둔 채 읽고 관리하고 검색하며, 여러 기기에서 접근할 수 있게 해 줍니다. 또 전달과 회신을 구별하세요. 전달, 포워드는 받은 메일을 다른 사람에게 그대로 보내는 것이고, 회신, 리플라이는 보낸 사람에게 답장을 보내는 것입니다. 답장을 보내는 기능을 전달이라고 한 보기는 틀린 내용입니다.

이제 두 번째 부분, 인터넷입니다. WWW는 웹 브라우저로 인터넷을 이용하게 해 주는 서비스입니다. 캐싱은 방문한 웹 페이지 정보를 임시로 저장했다가 다음에 빠르게 보여 주는 기능입니다. 쿠키는 방문 기록과 로그인 정보를 저장한 파일로, 매번 아이디와 비밀번호를 입력하지 않아도 자동으로 로그인되게 해 줍니다. 쿠키는 자주 출제됩니다. 미러 사이트는 접속자가 너무 많거나 너무 먼 곳이라 속도가 느려지는 것을 막기 위해, 원본과 같은 내용을 허가를 받아 복제해 둔 사이트입니다. 링크 사이트는 다른 사이트로 연결만 해 주는 사이트입니다. 플러그인은 브라우저에 기능을 추가하는 작은 보조 프로그램입니다.

인트라넷은 회사나 기관 내부에서만 쓰는 전용 네트워크이고, 엑스트라넷은 인트라넷을 확장해서 협력 업체까지 제한적으로 접속하게 한 것입니다. 유즈넷은 공통 관심사를 가진 사람들의 토론 서비스이고, 블루투스는 무선 마우스나 이어폰에 쓰는 근거리 무선 통신 기술입니다. 이더넷은 가장 일반적인 유선 랜 기술입니다.

인터넷 서비스입니다. VoIP는 인터넷으로 음성 통화를 하는 인터넷 전화입니다. 앞에 m이 붙은 mVoIP는 와이파이나 LTE 같은 무선망으로 하는 인터넷 전화입니다. 무선망이라는 말이 나오면 mVoIP입니다. 클라우드 컴퓨팅은 서버와 저장소와 소프트웨어를 인터넷으로 필요할 때 빌려 쓰는 서비스입니다. VPN은 가상 사설망으로, 인터넷에서 암호화된 터널을 만들어 사설망에 안전하게 접속하게 해 줍니다. RSS는 웹사이트의 새 소식을 자동으로 받아 보는 형식입니다. IPTV는 인터넷망으로 실시간 방송과 VOD를 보는 서비스로, 셋톱박스가 필요합니다. LBS는 위치 기반 서비스로, GPS와 와이파이로 현재 위치를 파악해서 지도나 길찾기 같은 정보를 제공합니다. 와이브로는 이동 중에도 쓰는 무선 휴대 인터넷입니다. 테더링은 스마트폰을 공유기처럼 써서 노트북이나 태블릿에서 인터넷을 쓰게 해 주는 기능이고, 핫스팟은 무선 인터넷을 쓸 수 있는 장소나 기능입니다. 로밍은 해외에서도 내 휴대폰으로 통화와 데이터를 쓰게 해 주는 서비스입니다.

최신 IT 기술입니다. IoT, 사물 인터넷은 사물과 사람과 공간을 인터넷으로 연결해서, 데이터를 수집하고 분석하고 판단해 지능화된 서비스를 스스로 제공하는 기술입니다. 사물 인터넷을 쓰면 통신 비용이 줄고 보안 적용이 쉬워진다는 보기는 틀린 내용입니다. 실제로는 연결된 기기가 많아 통신 비용이 늘 수 있고, 보안은 아직 해결할 과제입니다. 빅데이터는 대용량, 다양성, 고속으로 만들어지는 방대한 데이터와 그것을 분석하는 기술입니다. 메타버스는 가상과 현실이 융합된 3차원 공간에서 아바타로 활동하는 플랫폼입니다. 블록체인은 거래 기록을 여러 컴퓨터에 나눠 저장해서 위조와 변조를 막는 기술입니다. 유비쿼터스는 언제 어디서나 네트워크에 접속할 수 있는 환경입니다.

RFID, NFC, USN 세 가지는 꼭 구별하세요. RFID는 무선 주파수로 사물에 붙은 전자 태그의 정보를 접촉하지 않고 읽는 기술로, 출입 통제나 도서 대출에 씁니다. NFC는 10센티미터 이내의 아주 가까운 거리에서 무선으로 데이터를 주고받는 기술로, 모바일 결제나 교통카드에 씁니다. USN은 센서로 현실 세계의 정보를 모아서 네트워크로 실시간 전송하고 관리하는 기술로, 스마트팜이나 산불과 홍수 감지에 씁니다. 태그는 RFID, 10센티미터는 NFC, 센서는 USN입니다. 텔레매틱스는 차량에 정보통신 기술을 접목해서 교통, 위치, 긴급 구조 서비스를 제공하는 기술입니다.

이제 IP 주소입니다. IP 주소는 인터넷에 연결된 모든 장치를 구별하기 위한 고유한 주소입니다. 기존의 IPv4는 주소가 부족해서, 이를 해결하려고 IPv6가 나왔습니다. 시험에는 IPv6가 많이 나옵니다. IPv4는 32비트이고, 8비트씩 4부분을 점으로 구분합니다. A 클래스부터 E 클래스까지 나뉩니다. IPv6는 128비트이고, 16비트씩 8부분을 16진수로 쓰며 콜론으로 구분합니다. 클래스 구분이 없고, 인증과 암호화 기능이 기본으로 들어 있습니다. IPv4와의 호환성이 높고, 연속된 0은 생략해서 콜론 두 개로 표시할 수 있습니다. 주소 지정 방식은 유니캐스트, 멀티캐스트, 애니캐스트 세 가지입니다. IPv6가 8비트씩 16부분이라는 보기와, A부터 E 클래스로 나뉜다는 보기는 모두 틀린 내용입니다. 지금은 IPv4와 IPv6를 함께 쓰면서 점차 IPv6로 바뀌고 있습니다.

도메인 네임은 숫자로 된 IP 주소를 사람이 기억하기 쉽게 문자로 나타낸 것입니다. 전 세계에서 유일하며, 도메인 네임과 IP 주소는 같은 것이 아니고 DNS가 서로 바꿔 줍니다. 도메인을 관리하는 기관은 우리나라는 한국인터넷진흥원, KISA이고, 국제적으로는 ICANN입니다. 인터넷이 하나의 중앙 통제 기구에 의해 운영된다는 보기는 틀린 내용입니다.

도메인의 기관 이름도 알아 두세요. go는 정부 기관, or은 비영리 기관, mil은 군사 기관, re는 연구 기관, co는 영리 기관, ne는 네트워크, pe는 개인입니다. 최근에는 학교 도메인이 출제되었습니다. 유치원은 kg, 초등학교는 es, 중학교는 ms, 고등학교는 hs, 대학은 ac, 기타 학교는 sc입니다. 고등학교가 sc라는 보기는 틀린 내용입니다.

URL은 인터넷에 있는 문서, 이미지, 동영상 같은 자원의 정확한 위치를 나타내는 주소입니다. 도메인이 집이라면 URL은 집까지 가는 전체 경로입니다. 형식은 프로토콜, 콜론 슬래시 슬래시, 호스트 서버 주소, 그다음 포트 번호, 그다음 파일 경로 순서입니다.

이제 세 번째 부분, 바이러스와 정보 보안입니다. 바이러스는 사용자 동의 없이 침투해서 자신을 복제하고 퍼뜨리며 시스템에 피해를 주는 악성 프로그램입니다. 예방하려면 방화벽을 설치하고, 최신 백신으로 주기적으로 검사하고, 다운로드한 파일은 실행하기 전에 검사합니다. 네트워크 공유 폴더는 읽기 전용으로 설정합니다. 출처가 불분명한 메일은 열지 말고 바로 삭제해야 합니다. 열어 보고 삭제한다거나, 본문을 확인하고 삭제한다는 보기는 틀린 내용입니다. 첨부 파일을 다른 이름으로 저장해서 쓰는 것도 예방법이 아닙니다.

악성 프로그램의 종류는 한 줄로 정리하세요. 웜은 자기 복제입니다. 스스로 복제해서 네트워크로 퍼지며 시스템을 느리게 하거나 다운시킵니다. 분산 서비스 거부 공격인 디도스, 버퍼 오버플로, 슬래머가 웜의 형태입니다. 트로이 목마는 숨어서 실행됩니다. 정상 프로그램으로 위장했다가 실행되면 악성 행위를 하며, 자기 복제 능력은 없습니다. 웜의 형태가 아닌 것을 고르라는 문제의 답은 트로이 목마입니다. 랜섬웨어는 파일을 암호화하고 금전을 요구합니다. 스파이웨어는 몰래 설치되어 개인 정보를 수집합니다. 드로퍼는 다른 악성 코드를 몰래 설치하는 전달자입니다. 매크로 바이러스는 엑셀이나 워드 같은 문서의 매크로로 감염됩니다. 그 밖에 부트 섹터를 감염시키는 부트 바이러스, 실행 파일을 감염시키는 파일 바이러스, 둘 다 감염시키는 부트 파일 바이러스가 있습니다.

방화벽은 외부 네트워크와 내부 네트워크 사이에서 외부의 불법 접근과 해킹을 막는 보안 시스템입니다. 허가된 사용자만 들어오게 하고, 기록을 남겨 침입을 역추적할 수 있습니다. 하지만 내부 사용자의 불법 행위는 막을 수 없고, 메일 바이러스나 피싱도 막기 어렵습니다. 방화벽이 바이러스 감염을 알려 준다는 보기는 틀린 내용입니다. 그것은 백신 프로그램의 역할입니다. 프록시 서버는 사용자와 인터넷 서버 사이에서 중계해 주는 대리 서버로, 캐시와 방화벽 기능을 함께 가지고 있습니다. 내 IP를 숨겨 보안을 높이고, 자주 쓰는 정보를 저장해 속도를 높입니다.

정보 사회의 역기능에는 정보 범죄 증가, 유해 정보 확산, 개인 정보 침해, 인터넷 중독, 정보 격차 심화가 있습니다. 정보 편중으로 계층 간 정보 차이를 줄일 수 있다는 보기는 틀린 내용입니다. 건강 문제로는 새 기술에 적응하지 못해 생기는 정신적 스트레스인 테크노 스트레스와, 컴퓨터를 오래 써서 목과 어깨와 허리가 아프고 시력이 떨어지는 VDT 증후군이 있습니다. 예방하려면 비밀번호를 주기적으로 바꾸고, 백신과 윈도우 업데이트를 자동으로 설정하고, 정크 메일, 즉 스팸 메일은 본문을 확인하지 말고 바로 삭제합니다.

데이터 보안 침해 형태는 자주 출제됩니다. 가로막기는 데이터가 수신자에게 전달되지 못하게 방해하는 것으로, 가용성을 침해합니다. 가용성은 필요한 사람이 언제든 정보를 쓸 수 있어야 한다는 뜻입니다. 가로채기는 전송 중인 데이터를 제3자가 몰래 보거나 도청하는 것으로, 기밀성을 침해합니다. 기밀성은 허가된 사람만 정보에 접근해야 한다는 뜻입니다. 수정, 또는 변조는 데이터 내용을 바꾸는 것이고, 위조는 정당한 송신자가 보낸 것처럼 가짜 데이터를 만드는 것입니다. 이 둘은 무결성을 침해합니다. 무결성은 정보가 바뀌거나 훼손되지 않고 올바르게 유지되어야 한다는 뜻입니다. 가로막기는 가용성, 가로채기는 기밀성, 수정과 위조는 무결성입니다.

마지막으로 정보 보안 위협입니다. 해킹은 시스템에 불법으로 침입하는 것입니다. 백도어는 유지보수용 비밀 통로를 해커가 침입 경로로 악용하는 것이고, 트랩도어는 개발자가 개발 단계에서 숨겨 둔 비밀 출입구입니다. 교재에 따라 둘을 같은 뜻으로 설명하기도 합니다. 피기배킹은 로그인한 채 자리를 비운 사이에 다른 사람이 그 컴퓨터로 작업하는 것입니다. 스푸핑은 속임수입니다. 믿을 수 있는 사용자나 사이트인 것처럼 속여서 정보를 가로챕니다. 스니핑은 엿보기입니다. 네트워크에서 아이디와 비밀번호를 몰래 엿봅니다. 스푸핑은 우로 끝나니 속임, 스니핑은 이로 끝나니 엿보기. 이렇게 외우면 헷갈리지 않습니다. 디도스는 여러 PC로 동시에 접속해 서버를 마비시키는 것이고, 피싱은 가짜 사이트나 가짜 메일로 금융 정보와 비밀번호를 입력하게 속이는 낚시입니다. 키로거는 키보드 입력을 몰래 기록해 계정 정보를 훔칩니다. 워 드라이빙은 차를 타고 이동하며 와이파이 정보를 수집하는 것이고, 허니팟은 꿀단지라는 뜻처럼 해커를 유인하려고 만든 가짜 시스템입니다. 스팸은 원하지 않는 광고 메일을 대량으로 보내는 것입니다.

정리하겠습니다. 피어 투 피어는 서버이자 클라이언트, 클라이언트 서버는 역할 분리와 분산 처리입니다. ISDN은 하나의 회선으로 통합, B-ISDN은 고속 디지털입니다. 성형은 중앙이 고장 나면 전체가 마비되고, 망형은 신뢰성이 가장 높습니다. 물리는 리피터, 데이터 링크는 브리지, 네트워크는 라우터, 전송은 게이트웨이입니다. DHCP는 IP 자동 할당, FTP는 파일 전송, SMTP는 보내기, POP3는 받기입니다. 쿠키는 자동 로그인, 미러 사이트는 복제 사이트, mVoIP는 무선 인터넷 전화입니다. RFID는 태그, NFC는 10센티미터, USN은 센서입니다. IPv6는 128비트, 16비트씩 8부분, 콜론, 클래스 없음입니다. 웜은 자기 복제, 트로이 목마는 위장, 랜섬웨어는 금전 요구입니다. 가로막기는 가용성, 가로채기는 기밀성, 수정과 위조는 무결성입니다. 스푸핑은 속임, 스니핑은 엿보기입니다. 오늘로 컴퓨터 일반 과목 공부를 모두 마쳤습니다. 수고하셨습니다.

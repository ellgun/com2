음성 원고 보기

컴퓨터 활용능력 2급 필기 7일차 음성 강의입니다. 오늘은 스프레드시트 일반에서 수식과 셀 참조, 오류 메시지, 이름 정의, 데이터 유효성 검사, 조건부 서식, 텍스트 나누기, 그리고 자동 필터와 고급 필터, 찾기와 바꾸기를 살펴보겠습니다. 필터와 조건부 서식은 필기와 실기 모두 자주 나오니 꼭 엑셀로 직접 따라 해 보세요.

먼저 수식입니다. 수식은 반드시 등호로 시작하고, 문자열은 큰따옴표로 묶습니다. 셀에 결과 대신 수식 자체를 보이게 하려면 컨트롤과 물결 키를 함께 누르거나, 수식 탭에서 수식 표시를 누릅니다. 계산은 셀 주소로 직접 계산하거나, 함수 이름을 직접 입력하거나, 함수 마법사를 이용하는 방법이 있습니다.

함수는 함수 이름과 인수로 이루어집니다. 인수가 없는 투데이 함수 같은 경우에도 괄호는 반드시 있어야 합니다. 인수를 구분할 때는 쉼표를 쓰고, 어디부터 어디까지라는 범위를 나타낼 때는 콜론을 씁니다. 썸 괄호 B2 콜론 C2는 B2부터 C2까지의 합이고, 썸 괄호 C3 쉼표 B2 쉼표 B4는 세 셀만 더하라는 뜻입니다. 함수 안에 함수를 넣는 중첩 함수는 최대 64개까지 가능합니다.

연산자도 알아 두세요. 산술 연산자는 더하기, 빼기, 곱하기, 나누기, 거듭제곱을 나타내는 꺾쇠, 그리고 백분율입니다. 비교 연산자에서 크다는 초과, 작다는 미만, 크거나 같다는 이상, 작거나 같다는 이하입니다. 같지 않다는 엑셀에서 작다 크다 기호를 붙여서 씁니다. 두 데이터를 하나로 연결하는 연결 연산자는 앤드 기호입니다.

다음은 셀 참조입니다. 반드시 이해하고 외워야 합니다. 상대 참조는 A1처럼 아무 기호가 없는 주소로, 채우기 핸들로 복사하면 행과 열이 모두 바뀝니다. 학생마다 합계를 구할 때처럼 주소가 따라 바뀌어야 할 때 씁니다. 절대 참조는 달러 A 달러 1처럼 행과 열 앞에 달러 기호가 붙은 주소로, 복사해도 절대 바뀌지 않습니다. 모든 학생에게 같은 셀의 가산점을 더할 때처럼 고정되어야 할 때 씁니다. 혼합 참조는 행이나 열 중 한쪽에만 달러가 붙은 것으로, 달러가 붙은 쪽만 고정됩니다. 참조 방식을 바꾸는 키는 F4이고, 누를 때마다 절대, 행 고정, 열 고정, 상대 순서로 바뀝니다. 참조한 셀의 값이 바뀌면 결과도 자동으로 다시 계산됩니다.

예를 들어 A7 셀에 등호 달러 A 달러 1 더하기 달러 A 2를 입력하고 C8까지 복사하면, 달러 A 달러 1은 그대로이고, 달러 A 2는 열은 고정되고 행만 한 칸 내려가서 달러 A 3이 됩니다.

다른 시트의 셀을 참조할 때는 시트 이름 뒤에 느낌표를 붙입니다. 시트 이름에 공백이 있거나 숫자로 시작하면 시트 이름을 작은따옴표로 감쌉니다. 다른 통합 문서를 참조할 때는 파일 이름을 대괄호로 묶습니다.

이제 오류 메시지입니다. 꾸준히 한 문제씩 나옵니다. 샵이 여러 개 나오는 것은 열 너비가 좁아서 숫자를 다 보여 주지 못하는 것이고, 열 너비를 넓히면 해결됩니다. DIV 슬래시 0은 0으로 나누었을 때 나옵니다. N 슬래시 A는 찾는 값이 없거나 사용할 수 없는 값을 지정했을 때 나옵니다. NAME은 함수 이름을 잘못 썼거나, 정의되지 않은 이름이나 삭제한 이름을 썼을 때 나옵니다. NULL은 교차하지 않는 두 범위를 공백으로 지정했거나, 콜론이나 쉼표가 빠졌을 때 나옵니다. NUM은 수치 범위를 벗어났거나 잘못된 숫자를 썼을 때, 예를 들어 음수의 제곱근을 구할 때 나옵니다. REF는 참조한 셀이나 행, 열을 삭제하는 등 셀 참조가 잘못되었을 때 나옵니다. VALUE는 숫자와 문자를 더하는 것처럼 잘못된 인수나 피연산자를 썼을 때 나옵니다. 수식이 자기 자신의 셀을 참조하면 순환 참조 경고가 나옵니다. REF가 숫자 인수 자리에 다른 인수를 넣었을 때 나온다는 보기는 틀린 내용입니다. 그것은 VALUE입니다.

다음은 이름 정의입니다. 셀이나 범위에 이름을 붙여서 수식에서 쉽게 쓰는 기능입니다. 범위를 선택하고 이름 상자에 이름을 입력한 뒤 엔터를 누르거나, 수식 탭의 이름 정의나 이름 관리자를 이용합니다. 이름 관리자의 단축키는 컨트롤 F3입니다. 선택 영역에서 만들기를 이용하면 첫 행 같은 머리글로 한꺼번에 이름을 만들 수 있습니다.

이름 규칙을 외워 두세요. 이름은 최대 255자까지이고, 첫 글자는 문자나 밑줄, 또는 역슬래시로 시작해야 합니다. 숫자나 슬래시로 시작할 수 없습니다. 공백은 쓸 수 없어서, 선택 영역에서 만들기를 하면 공백이 밑줄로 바뀝니다. A1 같은 셀 주소 형식은 이름으로 쓸 수 없고, 영문 대소문자는 구분하지 않으며, 같은 통합 문서 안에서 같은 이름을 중복해서 쓸 수 없습니다. 정의된 이름은 다른 시트에서도 쓸 수 있고, 기본적으로 절대 참조입니다. 이름이 상대 참조라는 보기는 틀린 내용입니다. 수식에 쓰던 이름을 삭제하면 NAME 오류가 납니다.

데이터 유효성 검사는 데이터 탭의 데이터 도구 그룹에 있습니다. 입력할 수 있는 데이터의 형식과 범위를 제한하는 기능입니다. 제한 대상은 모든 값, 정수, 소수점, 목록, 날짜, 시간, 텍스트 길이, 사용자 지정입니다. 그냥 텍스트라는 제한 대상은 없고, 텍스트 길이만 있다는 점을 기억하세요. 목록을 쓸 때는 남, 여처럼 원본 값을 쉼표로 구분해서 직접 입력하거나, 셀 범위를 지정하거나, 등호 뒤에 정의된 이름을 써도 됩니다. 드롭다운 목록의 너비는 셀 너비에 따라 정해지며 따로 지정할 수 없습니다. 목록 값을 세미콜론으로 구분한다는 보기는 틀린 내용입니다. 오류 메시지 탭에서는 중지, 경고, 정보 세 가지 스타일을 고를 수 있습니다. 유효성 검사를 없애려면 범위를 선택하고 모두 지우기를 누릅니다.

이제 두 번째 부분, 조건부 서식입니다. 조건부 서식은 홈 탭의 스타일 그룹에 있으며, 셀 값이나 수식이 조건을 만족하면 자동으로 서식을 적용합니다. 메뉴에는 셀 강조 규칙, 상위 하위 규칙, 데이터 막대, 색조, 아이콘 집합이 있습니다. 수식을 쓸 때는 새 규칙에서 수식을 사용하여 서식을 지정할 셀 결정을 고르고, 수식은 등호로 시작합니다.

행 전체에 서식을 적용하려면 열만 고정한 혼합 참조를 씁니다. 예를 들어 평점이 D열에 있다면 등호 달러 D 2 작다 3처럼 씁니다. 셀을 클릭하면 절대 참조로 들어가므로 F4를 두 번 눌러 열 고정으로 바꿉니다. 대출 금액이 평균보다 큰 행을 표시하려면, 대출 금액 셀은 열 고정으로, 평균을 구할 전체 범위는 절대 참조로 씁니다. 짝수 행에만 서식을 주려면 행 번호를 2로 나눈 나머지가 0인지 확인합니다. 로우 함수는 행 번호, 컬럼 함수는 열 번호, 모드 함수는 나머지를 구합니다.

조건부 서식에서 지정할 수 있는 서식은 표시 형식, 글꼴, 테두리, 채우기 네 가지입니다. 맞춤과 보호는 없습니다. 데이터가 바뀌면 조건부 서식도 자동으로 다시 적용되거나 해제됩니다. 여러 규칙이 충돌하면 규칙 관리자 목록에서 위에 있는 규칙이 우선이고, 순서는 바꿀 수 있습니다. 여러 조건을 동시에 만족하면 가장 나중에 만족한 조건이 적용된다는 보기는 틀린 내용입니다. 규칙을 고치거나 삭제할 때는 규칙 관리를, 한꺼번에 지울 때는 규칙 지우기를 씁니다. 중복 값 규칙에서 고유는 한 번만 나오는 값, 중복은 두 번 이상 나오는 값입니다.

텍스트 나누기는 데이터 탭의 데이터 도구 그룹에 있습니다. 한 셀에 들어 있는 텍스트를 여러 열로 나누는 기능으로, 마법사는 3단계입니다. 1단계에서 구분 기호로 분리할지, 너비가 일정하게 나눌지 고릅니다. 너비가 일정한 경우에는 구분선을 클릭해서 나눌 위치를 정합니다. 2단계의 구분 기호는 탭, 세미콜론, 쉼표, 공백, 기타이며, 두 개 이상의 구분 기호를 함께 쓸 수 있습니다. 구분 기호가 두 가지 이상이면 텍스트 나누기를 할 수 없다는 보기는 틀린 내용입니다. 3단계에서는 열의 데이터 서식을 정하거나, 특정 열을 가져오지 않도록 할 수 있습니다.

중복된 항목 제거는 체크한 열의 값이 같으면 중복으로 보고 하나만 남깁니다. 날짜만 체크하면 날짜가 같은 행은 하나만 남고, 날짜와 품목을 모두 체크하면 둘 다 같은 행만 지워집니다. 데이터 가져오기로는 텍스트, 웹, HTML, 데이터베이스, XML 파일을 가져올 수 있지만, 한글 파일과 MS 워드 파일은 가져올 수 없습니다.

이제 세 번째 부분, 필터입니다. 필터는 많은 데이터 중에서 필요한 자료만 걸러 내는 기능으로, 데이터 탭의 정렬 및 필터 그룹에 있습니다. 자동 필터는 목록 단추로 조건에 맞는 행만 보여 주고, 나머지는 숨깁니다. 원래 위치에서만 필터링되며, 다른 곳에 결과를 복사할 수는 없습니다. 필터를 해제하면 모든 데이터가 다시 보입니다. 필터를 쓰기 위해 미리 정렬할 필요는 없습니다.

자동 필터의 핵심은 이것입니다. 같은 열에서는 그리고와 또는, 즉 AND와 OR가 모두 가능합니다. 하지만 서로 다른 열 사이에서는 AND만 가능하고 OR는 할 수 없습니다. 판매 수량이 100 이상이고 200 이하인 것처럼 같은 열의 조건은 가능하지만, 주소가 서울이거나 직업이 학생인 것처럼 다른 열의 OR 조건은 자동 필터로 할 수 없습니다.

와일드카드 문자도 씁니다. 별표는 여러 글자, 물음표는 한 글자를 대신합니다. 컴활 별은 컴활로 시작하는 모든 글자, 별 컴활은 컴활로 끝나는 모든 글자, 별 컴활 별은 컴활이 포함된 모든 글자입니다. 김 물음표 물음표는 김으로 시작하는 세 글자이고, 물음표 영 별은 두 번째 글자가 영인 데이터입니다. 사용자 지정 필터에서 박으로 시작 또는 물음표 두 개라고 했다면, 박으로 시작하는 모든 이름과 두 글자인 모든 이름이 나옵니다. 박으로 시작하는 두 글자만 나온다는 보기는 틀린 내용입니다.

고급 필터는 정렬 및 필터 그룹의 고급에 있습니다. 조건을 워크시트에 직접 입력해서 필터링하며, 결과를 현재 위치에 보여 주거나 다른 장소에 복사할 수 있습니다. 대화상자에서 목록 범위, 조건 범위, 복사 위치를 지정하고, 동일한 레코드는 하나만 표시하도록 할 수도 있습니다. 조건 범위는 필드명을 포함한 표 형태로 만들고, 필드명은 원본과 똑같아야 합니다. 등호로 원본 필드명 셀을 참조해 가져오면 정확합니다.

고급 필터 조건은 같은 행에 쓰면 AND, 다른 행에 쓰면 OR입니다. 같은 행은 이고, 이면서로 읽고, 다른 행은 이거나로 읽습니다. 예를 들어 성별 아래에 여, 평균 아래 같은 행에 60 이상을 쓰면 성별이 여이고 평균이 60 이상인 데이터입니다. 평균 조건을 다음 행에 쓰면 성별이 여이거나 평균이 60 이상인 데이터가 됩니다. 고급 필터 결과를 정렬해도 숨겨진 레코드는 정렬되지 않습니다.

고급 필터에서 조건에 함수를 쓰는 수식 조건도 필기에 자주 나옵니다. 이때는 필드명을 원본 필드명과 다르게 써야 합니다. 예를 들어 판매 수량 대신 평균이나 조건이라고 씁니다. 수식은 등호로 시작하고, 결과는 TRUE나 FALSE로 표시됩니다. 비교할 첫 데이터 셀은 상대 참조로, 평균을 구할 전체 범위는 절대 참조로 써야 합니다. 판매 수량이 평균 이상인 데이터를 찾는다면, 필드명은 평균, 조건은 등호 B2 크거나 같다 에버리지 괄호 달러 B 달러 2 콜론 달러 B 달러 8입니다. 원본 필드명을 그대로 쓴 보기나, 평균 범위가 절대 참조가 아닌 보기는 틀린 답입니다.

마지막으로 찾기와 바꾸기입니다. 찾기는 컨트롤 F, 또는 시프트 F5이고, 바꾸기는 컨트롤 H입니다. 범위는 시트와 통합 문서 중에서 고르고, 찾는 위치는 수식, 값, 메모입니다. 메모 안의 텍스트는 찾을 수 없다는 보기는 틀린 내용입니다. 대소문자 구분, 전체 셀 내용 일치, 전자 반자 구분 옵션이 있고, 숫자 셀을 포함해서 서식으로도 찾고 바꿀 수 있습니다. 와일드카드를 쓸 수 있으며, 별표나 물음표 같은 와일드카드 문자 자체를 찾으려면 앞에 물결 기호를 붙입니다. 시프트를 누른 채 다음 찾기를 누르면 이전 항목을 찾고, 모두 찾기를 누르면 조건에 맞는 항목이 모두 나열됩니다. 바꾸기에서는 내용과 서식을 한꺼번에 바꿀 수 있습니다.

정리하겠습니다. 수식은 등호로 시작하고, 컨트롤 물결로 수식을 표시하며, 중첩 함수는 64개까지입니다. F4로 참조를 바꾸고, 달러가 붙은 쪽은 고정됩니다. 다른 시트는 느낌표, 공백이 있는 시트 이름은 작은따옴표, 다른 파일은 대괄호입니다. DIV 0은 0으로 나눔, NAME은 이름 오류, REF는 참조 삭제, VALUE는 숫자와 문자 연산, NULL은 공백, N A는 값 없음입니다. 이름은 255자까지, 공백 불가, 대소문자 구분 안 함, 절대 참조입니다. 유효성 검사에는 텍스트 길이가 있고, 목록은 쉼표로 구분합니다. 조건부 서식에서 행 전체는 열 고정 혼합 참조, 서식은 표시 형식과 글꼴과 테두리와 채우기입니다. 텍스트 나누기는 구분 기호 여러 개를 함께 쓸 수 있고, 한글과 워드 파일은 가져올 수 없습니다. 자동 필터는 다른 열 사이에 AND만 되고, 고급 필터는 같은 행이 AND, 다른 행이 OR입니다. 수식 조건의 필드명은 원본과 다르게, 평균 범위는 절대 참조입니다. 찾기는 컨트롤 F, 바꾸기는 컨트롤 H, 와일드카드 자체는 물결을 붙여 찾습니다. 오늘 강의는 여기까지입니다. 수고하셨습니다.

컴퓨터 활용능력 2급 필기 — 2일차 핵심 정리

출처: 2일차 강의 3편을 Lilys AI(Readray)로 분석해 요약·재구성했습니다. 실제 Windows 버전에 따라 메뉴 위치가 다를 수 있습니다.

Part 1. 파일 탐색기 · 폴더 옵션 · 보조 프로그램

1-1. 파일 탐색기

  • 컴퓨터 안의 자료를 보고 정리하는 프로그램, 실행 Win + E
  • 왼쪽 탐색 창(폴더 구조)과 오른쪽 내용 창으로 구성, 폴더 안에 폴더가 들어가는 계층 구조
  • 폴더 앞 기호: 접힌 모양 = 하위 폴더가 숨겨진 상태, 펼쳐진 모양 = 하위 폴더 표시 상태
키동작
숫자 키패드 *선택한 폴더의 하위 폴더를 모두 펼침
숫자 키패드 + / −선택한 폴더 확장 / 축소
Backspace상위 폴더로 이동 (글자 지우기가 아님)
F3검색창으로 이동

1-2. 이동 · 복사 (시험 단골 함정)

조건그냥 드래그키를 누르면
같은 드라이브이동Ctrl + 드래그 → 복사
다른 드라이브 (C → USB)복사Shift + 드래그 → 이동
어느 드라이브든—Alt + 드래그 → 바로 가기 생성
  • 연속 선택 Shift+클릭, 떨어진 파일 Ctrl+클릭, 전체 선택 Ctrl+A(Alt+A ✗), 선택 해제 Ctrl+클릭

1-3. 폴더 옵션 (파일 탐색기 → 파일 탭 → 옵션)

  • 일반 탭: 같은 창/새 창에서 열기, 한 번/두 번 클릭, 탐색기 기록 삭제, 기본값 복원
  • 보기 탭: 숨김 파일·폴더 표시, 시스템 파일 표시, 확장명 숨김, 제목 표시줄에 전체 경로 표시
  • 검색 탭: 하위 폴더 포함, 압축 파일 포함 검색
  • 함정: 숨김 속성을 일괄 해제하는 기능은 없음 (보기 탭은 숨김 항목을 보이게 할지만 정함)

1-4. 보조 프로그램

프로그램핵심 특징
메모장서식 없는 텍스트 편집기, .txt, F5 = 날짜·시간 삽입, 찾기·바꾸기·자동 줄 바꿈. OLE 개체 삽입 불가, 일부 글자만 서식 지정 불가
스티커 메모바탕 화면 메모, 색·간단한 서식·그림 삽입 가능, 머리글·바닥글 불가
그림판비트맵 편집, OLE 지원, Shift를 누르고 그리면 수평·수직선, 정원, 정사각형, 바탕 화면 배경으로 사용 가능
캡처 도구사각형·자유형·창·전체 화면, 저장 형식 PNG·JPG·GIF, Win+Shift+S
Windows Media Player재생, CD 복사, 인터넷 라디오 / 동영상 편집 불가
실행 창 · 명령 프롬프트Win+R / 실행 창에 cmd

1-5. Part 1 시험 포인트

  • Backspace 상위 폴더, F3 검색, 키패드 * 모두 펼치기
  • 같은 드라이브 = 이동, 다른 드라이브 = 복사, Ctrl·Shift는 반대로, Alt는 바로 가기
  • 메모장 OLE 불가·F5 날짜, 스티커 메모 머리글 불가, 캡처는 PNG·JPG·GIF

Part 2. Windows 설정

2-1. 설정 열기와 항목

  • 설정 열기 Win + I (시작 단추 클릭·우클릭 → 설정)
항목주요 기능
앱설치된 앱 확인·제거, 기본 앱, 오프라인 지도, 시작 프로그램 (삭제된 프로그램 복원 기능 ✗)
시스템디스플레이(해상도·방향·배율·글자 크기·다중 모니터), 정보(PC 이름·사양·Windows 버전)
개인 설정배경, 잠금 화면(화면 보호기), 테마(배경·색·소리·커서 묶음), 글꼴, 시작·작업 표시줄
접근성돋보기, 내레이터, 고대비, 마우스 포인터 (Win + U)
계정로그인 방식, 가족·다른 사용자 추가
업데이트 및 보안Windows 업데이트(최대 35일 일시 중지), 정품 인증, 백업, 복구
  • 함정: 해상도는 개인 설정이 아니라 디스플레이, 정품 인증은 정보가 아니라 업데이트 및 보안, 바탕 화면 가젯은 Windows 7까지
  • 글꼴: 압축을 풀어 설치하거나 C:\Windows\Fonts 폴더에 복사

2-2. 접근성 · 돋보기

항목내용
실행 / 종료Win + (+) / Win + Esc
전체 화면화면 전체 확대
렌즈마우스 포인터 주변만 확대
도킹화면 한쪽에 확대 영역을 따로 표시
  • 내레이터: 글자뿐 아니라 버튼·메뉴 등 UI 요소까지 읽어 줌. 숫자 키패드로 포인터 이동은 접근성 → 마우스, 왼손잡이·더블클릭 속도·포인터 모양은 장치 → 마우스

2-3. 계정

구분표준 계정관리자 계정
설정 변경다른 사용자나 보안에 영향 없는 것만모든 설정
다른 계정 관리불가가능
가능한 것자신의 암호·바탕 화면·포인터 변경모든 파일·프로그램 접근
  • 관리자가 설치한 프린터 제거는 표준 계정이 할 수 없음

2-4. Part 2 시험 포인트

  • 설정 Win+I, 접근성 Win+U, 돋보기 Win+(+) / Win+Esc
  • 렌즈 = 포인터 주변, 도킹 = 한쪽에 고정
  • 디스플레이 = 해상도, 개인 설정 = 테마·배경, 업데이트 및 보안 = 정품 인증·35일

Part 3. 관리 도구 · 파일 시스템 · 장치 관리자 · 작업 관리자

3-1. 관리 도구

도구기능포인트
디스크 검사하드디스크 오류 찾아 수정CD-ROM·네트워크 드라이브 불가
디스크 정리불필요한 파일 삭제 → 용량 증가휴지통·임시 파일·다운로드·임시 인터넷 파일 (글꼴 ✗)
드라이브 최적화(조각 모음)흩어진 조각을 모아 속도 향상USB 가능, CD-ROM·네트워크 불가, 예약 가능
포맷저장 장치 초기화용량·파일 시스템·할당 단위·볼륨 레이블·빠른 포맷

3-2. 파일 시스템

종류특징
FAT 계열호환성 높음, 파일 하나 4GB 이하, USB 등
exFAT4GB 제한 개선, NTFS보다 안정성 낮음
NTFSWindows 기본, 안정성·대용량·보안·압축·복구, 시스템 리소스를 적게 사용

3-3. 장치 관리자 · 작업 관리자 · 레지스트리

  • 장치 관리자(시작 단추 우클릭): 노란 물음표 = 드라이버 미설치, 노란 느낌표 = 정상 작동 안 함, X = 사용 안 함
  • 작업 관리자(Ctrl+Shift+Esc): 프로세스(작업 끝내기), 성능(CPU·메모리·디스크·이더넷), 앱 기록 — 실행 중인 프로그램의 표시 순서는 바꿀 수 없음
  • 레지스트리: 환경 설정·시스템 정보를 계층 구조로 기록한 데이터베이스, regedit, 잘못 편집하면 데이터 손실 가능 → 편집 전 백업

3-4. Part 3 시험 포인트

  • 용량 늘리기 = 디스크 정리, 속도 높이기 = 조각 모음·최적화
  • FAT 4GB 이하, NTFS 보안·안정성·리소스 최소
  • ? 미설치, ! 비정상, X 사용 안 함 / 작업 관리자 순서 변경 불가

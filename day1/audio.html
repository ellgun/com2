컴퓨터 활용능력 2급 필기 1일차 핵심 정리 음성 파일입니다. 컴퓨터 일반 과목의 운영체제, 윈도우, 휴지통과 바로 가기 아이콘을 순서대로 설명합니다.

첫 번째, 운영체제입니다. 운영체제는 사용자와 컴퓨터 사이에서 시스템을 효율적으로 운영하는 인터페이스 역할을 합니다. 스마트폰과 노트북 같은 정보 기기에도 반드시 설치되는 대표적인 시스템 소프트웨어입니다. 종류로는 윈도우 10, 윈도우 11, MS-DOS, 유닉스, 리눅스, 맥 O S, 크롬 O S, O S 투 등이 있습니다.

시험 함정 하나 짚겠습니다. 운영체제는 컴퓨터가 꺼져 있을 때는 하드디스크나 S S D에 저장되어 있지만, 작동 중에는 메모리에서 실행됩니다. 하드디스크에서 실행된다는 보기는 틀린 설명입니다.

운영체제의 성능 평가 항목은 네 가지입니다. 신뢰도는 주어진 문제를 정확하게 처리하는 정도이고, 사용 가능도는 필요할 때 즉시 쓸 수 있는 정도입니다. 처리 능력은 일정 시간 동안 처리하는 일의 양입니다. 이 세 가지는 높을수록 좋습니다. 응답 시간은 명령을 내린 뒤 결과가 나올 때까지 걸리는 시간이므로 짧을수록 좋습니다.

운영체제의 구성은 제어 프로그램과 처리 프로그램으로 나뉩니다. 제어 프로그램에는 감시 프로그램, 작업 관리 프로그램, 데이터 관리 프로그램이 있습니다. 처리 프로그램에는 언어 번역 프로그램, 서비스 프로그램, 문제 처리 프로그램이 있습니다. 언어 번역은 처리 프로그램이라는 점을 기억하세요.

운영 방식은 여러 가지입니다. 일괄 처리는 데이터를 모아서 한꺼번에 처리하는 방식으로, 급여 지급이나 전기요금 청구가 예입니다. 실시간 처리는 입력과 동시에 즉시 처리하는 방식으로, 에이 티 엠이나 기차표 예약이 예입니다. 시분할 처리는 C P U 시간을 잘게 나눠 여러 작업을 번갈아 처리합니다. 다중 처리는 C P U가 두 개 이상이고, 다중 프로그래밍은 C P U 한 개로 여러 프로그램을 동시에 처리합니다.

듀얼 시스템은 두 C P U가 같은 작업을 동시에 수행합니다. 듀플렉스 시스템은 한 C P U가 작업하는 동안 다른 C P U는 대기하다가, 고장이 나면 교체되어 들어갑니다. 분산 처리는 여러 컴퓨터가 연결되어 작업을 나눠 처리하고, 클러스터링은 두 대 이상의 컴퓨터를 하나처럼 묶어 씁니다. 임베디드 시스템은 하드웨어와 소프트웨어가 결합된 전용 제어 시스템으로, 냉장고나 T V 같은 가전제품에 들어갑니다.

발달 순서는 일괄 처리가 처음이고, 분산 처리가 마지막입니다. 나머지는 그 사이에 옵니다.

두 번째, 윈도우입니다. 윈도우의 특징은 다음과 같습니다. 지 유 아이는 그래픽 요소를 마우스로 조작하는 방식이고, 예전의 씨 엘 아이는 명령어를 직접 입력하는 방식입니다. 선점형 멀티태스킹은 운영체제가 각 프로그램의 C P U 사용 시간을 자동으로 나눠 줍니다.

피엔피, 플러그 앤 플레이는 장치를 연결하면 자동으로 인식하고 별도 설치가 필요 없는 기능입니다. 핫 플러그는 컴퓨터를 끄지 않은 상태에서 장치를 연결하거나 교체하는 기능입니다. 두 개를 헷갈리지 않도록 구분하세요. 윈도우는 64비트를 지원하고, 엔 티 에프 에스 파일 시스템을 씁니다. 오 엘 이 기능은 프로그램 사이에서 데이터를 연결하거나 삽입하는 기능입니다.

에어로 기능도 나옵니다. 에어로 피크는 창을 투명하게 해서 바탕화면을 미리 보는 기능입니다. 에어로 스냅은 창을 화면 가장자리에 맞춰 정렬합니다. 에어로 셰이크는 제목 표시줄을 흔들면 그 창만 남기고 나머지를 최소화합니다. 점프 목록은 작업 표시줄 아이콘을 우클릭하면 최근 사용 항목이 나오는 기능입니다. 라이브러리는 여러 폴더에 흩어진 파일을 종류별로 모아 보여 줍니다.

폴더와 파일 규칙도 중요합니다. 같은 폴더 안에 같은 이름의 파일이나 폴더는 둘 수 없습니다. 파일 이름은 최대 255자입니다. 폴더 속성 창에는 일반, 공유, 보안, 사용자 지정 탭이 있고, 속성 창에서는 폴더를 삭제할 수 없습니다. 압축은 저장 공간과 전송 시간을 줄이기 위한 기능입니다. 이미 압축된 파일을 다시 압축해도 계속 작아지지는 않습니다.

단축키는 꼭 외워 두세요. 에프 투는 이름 바꾸기, 에프 삼은 검색, 에프 사는 주소 표시줄, 에프 오는 새로 고침입니다. 네 키 모두 컨트롤 키 없이 단독으로 누릅니다. 컨트롤 디는 휴지통으로 삭제, 컨트롤 에프 포 또는 컨트롤 더블유는 창 닫기입니다. 컨트롤 쉬프트 엔은 새 폴더를 만듭니다. 쉬프트 딜리트는 휴지통을 거치지 않고 완전히 삭제합니다.

캡처는 프린트 스크린이 화면 전체를 클립보드에 복사하고, 알트 프린트 스크린은 활성 창만 복사합니다. 윈도우 키와 프린트 스크린을 같이 누르면 파일로 자동 저장됩니다. 윈도우 키와 쉬프트와 에스를 누르면 드래그한 영역만 캡처합니다.

창 제어 키도 중요합니다. 이에스씨는 취소나 슬라이드쇼 종료입니다. 알트 에프 포는 창을 닫습니다. 컨트롤 알트 딜리트는 선택 화면을 띄우고, 컨트롤 쉬프트 이에스씨는 작업 관리자를 바로 엽니다. 컨트롤 이에스씨는 시작 메뉴입니다. 쉬프트 에프 텐은 바로 가기 메뉴입니다. 알트 엔터는 속성 창을 엽니다. 알트 스페이스바는 창 조절 메뉴입니다. 알트 탭과 알트 이에스씨는 창 전환, 컨트롤 알트 탭은 창 목록을 보여 주는데 키를 떼도 화면이 유지됩니다.

윈도우 키 조합도 있습니다. 윈도우 에이는 알림 센터, 윈도우 디는 바탕화면 표시, 윈도우 이는 파일 탐색기, 윈도우 에프는 피드백 허브, 윈도우 아이는 설정, 윈도우 엘은 잠금, 윈도우 엠은 모든 창 최소화입니다. 윈도우 알은 실행 창, 윈도우 에스는 검색, 윈도우 티는 작업 표시줄 이동, 윈도우 탭은 작업 보기입니다.

세 번째, 휴지통과 바로 가기 아이콘입니다. 휴지통은 삭제한 파일을 임시로 보관해서 복원할 수 있게 합니다. 드라이브마다 휴지통을 따로 둘 수 있습니다. 용량이 가득 차면 새 파일은 정상적으로 들어가고, 가장 먼저 들어온 파일부터 자동으로 삭제됩니다. 휴지통 안의 파일은 이름을 바꾸거나 그 자리에서 실행할 수 없고, 먼저 복원해야 합니다.

휴지통을 거치지 않고 바로 삭제되는 경우가 있습니다. 쉬프트 딜리트를 누른 경우, USB 메모리나 외장 하드, 네트워크 드라이브에서 삭제한 경우, 휴지통 크기를 0 퍼센트로 설정한 경우, 그리고 휴지통 비우기를 실행한 경우입니다.

바로 가기 아이콘은 원본 프로그램이 아니라 원본의 경로를 기억하는 연결 아이콘입니다. 확장자는 엘 엔 케이입니다. 바로 가기를 지워도 원본은 남습니다. 하지만 원본을 지우면 바로 가기로 실행할 수 없습니다. 한 원본에 대해 바로 가기를 여러 개, 개수 제한 없이 만들 수 있고, 원본 위치와 관계없이 다른 위치에도 만들 수 있습니다.

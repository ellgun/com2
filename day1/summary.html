Part 1. 운영체제 (OS)

1-1. 개념

  • 사용자와 컴퓨터 사이에서 시스템을 효율적으로 운영하는 인터페이스 역할
  • 응용 프로그램을 편리하게 쓰게 하고 하드웨어 성능을 최적화
  • 컴퓨터·스마트폰·노트북 등에 반드시 설치되는 대표적인 시스템 소프트웨어
  • 종류: Windows 10/11, MS-DOS, UNIX, Linux, macOS, Chrome OS, OS/2
  • 실행 위치: 꺼져 있을 때는 하드디스크/SSD에 저장, 작동 중에는 메모리(주기억장치)에서 실행 (기출 함정)

1-2. 성능 평가 항목

항목뜻좋은 방향
신뢰도주어진 문제를 정확하게 처리하는 정도높을수록
사용 가능도필요할 때 즉시 사용할 수 있는 정도높을수록
처리 능력일정 시간 동안 처리하는 일의 양높을수록
응답 시간명령 후 결과가 나올 때까지 걸리는 시간낮을수록

1-3. 구성 프로그램

  • 제어 프로그램: 감시, 작업 관리, 데이터 관리
  • 처리 프로그램: 언어 번역, 서비스, 문제 처리
  • 함정: 언어 번역은 처리 프로그램 (제어 프로그램 목록에 넣으면 ✗)

1-4. 운영 방식

방식설명예시
일괄 처리데이터를 모아 한꺼번에 처리급여 지급, 전기요금 청구
실시간 처리입력과 동시에 즉시 처리ATM, 기차표 예약
시분할 처리CPU 시간을 잘게 나눠 여러 작업을 번갈아 처리다수 사용자 동시 이용
다중 처리CPU가 2개 이상작업 분담, 속도·안정성 향상
다중 프로그래밍CPU 1개로 여러 프로그램을 동시 처리CPU 유휴 시간 최소화
듀얼 시스템두 CPU가 같은 작업을 동시에 수행두 컴퓨터가 함께 시작
듀플렉스 시스템한 CPU가 작업, 다른 CPU는 대기 (고장 시 교체 투입)고장 대비
분산 처리여러 컴퓨터가 연결되어 작업을 나눠 처리네트워크 기반
클러스터링두 대 이상의 컴퓨터를 하나처럼 묶어 사용서버 묶음
임베디드 시스템하드웨어와 소프트웨어가 결합된 전용 제어 시스템냉장고, TV, 자동차
  • 발달 순서: 일괄 처리가 처음, 분산 처리가 마지막

1-5. Part 1 시험 포인트

  • 운영체제는 작동 중 메모리에서 실행
  • 신뢰도·사용 가능도·처리 능력은 높게, 응답 시간은 낮게
  • 제어 프로그램 = 감시·작업 관리·데이터 관리, 나머지는 처리 프로그램
  • 듀얼 = 동시 수행, 듀플렉스 = 한쪽 대기

Part 2. Windows

2-1. 주요 특징

  • GUI: 아이콘·메뉴를 마우스로 조작 (예전 CLI는 명령어 직접 입력)
  • 선점형 멀티태스킹: 운영체제가 각 프로그램의 CPU 사용 시간을 자동 배분
  • PnP(플러그 앤 플레이): 장치를 연결하면 자동 인식, 별도 설치 불필요
  • 핫 플러그: 컴퓨터를 끄지 않고 장치를 연결·교체 — PnP와 혼동하게 출제되니 구분 필수
  • 64비트 지원, NTFS 파일 시스템(보안·압축·권한 설정)
  • OLE: 프로그램 간 데이터 연결·삽입 (엑셀 표를 워드에 넣고 원본 수정 시 자동 반영)

2-2. Aero 기능과 점프 목록

기능설명
Aero Peek열린 창을 투명하게 해 바탕 화면 미리 보기 (Win+D와 같은 효과)
Aero Snap창을 화면 가장자리에 맞춰 정렬
Aero Shake제목 표시줄을 흔들면 그 창만 남기고 나머지 최소화 (다시 흔들면 복원)
점프 목록작업 표시줄 아이콘을 우클릭하면 최근 사용 항목 표시 (고정·제거 가능)
라이브러리여러 폴더에 흩어진 파일을 종류별로 모아 보기 (실제 위치는 다름)

2-4. 작업 표시줄 · 검색 · 폴더 · 압축

  • 작업 표시줄: 크기 조절(화면 절반까지), 잠금, 자동 숨기기 — 작업 표시줄 우클릭 → 작업 표시줄 설정. 실제 없는 기능을 오답으로 냄
  • 검색(Win+S): 프로그램 실행, 웹 주소 이동 가능 / 파일 압축·복원은 불가
  • 같은 폴더 안에 같은 이름의 파일·폴더 불가, 파일 이름은 최대 255자, 쓸 수 없는 문자가 있음
  • 폴더 속성 탭: 일반, 공유, 보안, 사용자 지정 — 속성 창에서는 폴더 삭제 불가
  • 압축: 저장 공간 절약, 전송 시간 단축, Windows가 ZIP 압축 기본 제공. 다시 압축해도 계속 줄지는 않음

2-5. Part 2 시험 포인트

  • PnP = 자동 인식·설치 불필요, 핫 플러그 = 전원을 끄지 않고 교체
  • Alt+Enter 속성, Shift+F10 바로 가기 메뉴, Ctrl+Esc 시작 메뉴, Win+F 피드백 허브
  • Print Screen 전체, Alt+Print Screen 활성 창, Shift+Delete 완전 삭제

Part 3. 휴지통과 바로 가기 아이콘

3-1. 휴지통

  • 삭제한 파일을 임시 보관, 복원 가능. 드라이브마다 하나씩
  • 용량 초과 시: 새 파일은 정상적으로 들어가고, 가장 먼저 들어간 파일부터 자동 삭제 (“새 파일은 보관되지 않는다” ✗)
  • 비어 있을 때와 파일이 있을 때 아이콘 모양이 다름
  • 휴지통 안의 파일은 이름 변경·실행 불가 (복원 후 실행)
  • 기본 크기는 드라이브 용량의 10% 미만, 사용자가 조정 가능. 속성: 휴지통 선택 후 Alt+Enter
휴지통을 거치지 않고 바로 삭제되는 경우 (복원 불가)
Shift+Delete · Shift를 누른 채 휴지통으로 드래그 · USB·외장 하드·네트워크 드라이브에서 삭제 · 휴지통 크기 0% · 휴지통 비우기

3-2. 바로 가기 아이콘

  • 아이콘 왼쪽 아래에 꺾인 화살표, 다른 이름 단축 아이콘, 확장자 .lnk
  • 원본 파일의 경로를 기억하는 아이콘 — 바로 가기를 지워도 원본은 그대로, 원본을 지우면 실행 불가
  • 한 원본에 여러 개, 개수 제한 없이 만들 수 있음 (“하나만 가능” ✗)
  • 대상: 프로그램, 파일, 폴더, 디스크 드라이브, 프린터 등, 원본과 다른 위치에도 생성 가능

3-3. Part 3 시험 포인트

  • 휴지통: 드라이브마다 하나, 초과 시 오래된 파일부터 삭제, 이름 변경·실행 불가
  • 바로 삭제: Shift+Delete, USB·외장·네트워크, 크기 0%
  • 바로 가기: .lnk, 여러 개 가능, 원본 삭제 시 실행 불가

Part 1. 수식 · 셀 참조 · 오류 · 이름 정의 · 유효성 검사

1-1. 수식과 함수

  • 수식은 반드시 등호(=)로 시작. 문자열은 큰따옴표(" ")로 묶음
  • 셀에 결과 대신 수식 자체를 표시: Ctrl + `(물결 키) 또는 [수식] 탭 → 수식 표시
  • 계산 방법: 직접 계산(=B3+C3), 함수 직접 입력(=SUM(B3:C3)), 함수 마법사(fx)
  • 함수 = 함수 이름 + 인수. 인수는 숫자·텍스트·논리값·셀 참조 등. 인수가 없어도 괄호는 반드시 필요 (예: =TODAY())
  • 인수 구분은 쉼표(,) · 범위(어디부터 어디까지)는 콜론(:)
    예) =SUM(B2:C2) = B2부터 C2까지 / =SUM(C3,B2,B4) = 세 셀만
  • 함수 안에 함수를 넣는 중첩 함수는 최대 64개까지
연산자기호
산술+ − * / , ^(거듭제곱), %(백분율)
비교= 같다, > 크다(초과), < 작다(미만), >= 이상, <= 이하, <> 같지 않다
연결& (두 데이터를 하나로 연결)

1-2. 셀 참조 (반드시 이해·암기)

종류표시채우기 핸들로 복사하면
상대 참조A1행·열이 모두 바뀜 (사람마다 합계 구할 때)
절대 참조$A$1절대 바뀌지 않음 (모두에게 같은 가산점 셀을 더할 때)
혼합 참조$A1 / A$1$가 붙은 쪽만 고정
  • 참조 방식 전환 키: F4 (A1 → $A$1 → A$1 → $A1 → A1)
  • 참조한 셀의 값이 바뀌면 결과도 자동으로 다시 계산
  • 예제: A7에 =$A$1+$A2 입력 후 C8까지 복사 → C8은 =$A$1+$A3 (열 고정, 행만 1 증가)

1-3. 다른 시트·통합 문서 참조

  • 다른 시트: 시트이름!셀 → =Sheet2!A1
  • 시트 이름에 공백이 있거나 숫자로 시작하면 작은따옴표로 감쌈 → ='2월 매출'!A1
  • 다른 통합 문서: 파일 이름을 대괄호[ ]로 → ='[1학년 1반.xlsx]기말고사'!A5

1-4. 오류 메시지 (꾸준히 1문제)

오류원인
#####열 너비가 좁아 숫자를 다 표시하지 못함 (열 너비를 넓히면 해결)
#DIV/0!0으로 나눔
#N/A찾는 값이 없거나 사용할 수 없는 값 지정 (예: VLOOKUP으로 없는 값 검색)
#NAME?함수 이름 오타, 정의되지 않은(삭제된) 이름 사용, 텍스트 따옴표 누락
#NULL!교차하지 않는 두 범위를 공백으로 지정, 콜론·쉼표 누락 (예: =SUM(C4:C6 D4:D6))
#NUM!수치 범위를 벗어나거나 잘못된 숫자 사용 (예: 음수의 제곱근 =SQRT(-4))
#REF!참조한 셀(행·열)을 삭제하는 등 셀 참조가 잘못됨
#VALUE!잘못된 인수·피연산자 (예: 숫자 + 문자, 날짜 함수에 문자 입력)
순환 참조 경고수식이 자기 자신의 셀을 참조 (예: D13에 =SUM(D2:D13))
  • 함정: “#REF! = 숫자 인수가 필요한 곳에 다른 인수 지정” ✗ (그건 #VALUE!)

1-5. 이름 정의

  • 셀·범위에 이름을 붙여 수식에서 쉽게 사용 (=SUM(판매금액))
  • 방법: 범위 선택 후 이름 상자에 입력하고 Enter / [수식] → 이름 정의 / 이름 관리자(Ctrl + F3) / 선택 영역에서 만들기(첫 행 등)
  • 규칙
    • 최대 255자, 첫 글자는 문자·밑줄(_)·역슬래시(\) (숫자·슬래시로 시작 불가)
    • 공백 사용 불가 → 선택 영역에서 만들기를 하면 공백이 밑줄(_)로 바뀜 (공백 수만큼)
    • A1 같은 셀 주소 형식은 불가, 영문 대·소문자 구분 안 함, 같은 통합 문서 안에서 중복 불가
    • 정의된 이름은 다른 시트에서도 사용 가능, 기본적으로 절대 참조
  • 수식에 쓰던 이름을 삭제하면 #NAME? 오류
  • 함정: “이름은 기본적으로 상대 참조” ✗ · “꽃 명 → 이름 상자에 꽃명 표시” ✗ (꽃_명)

1-6. 데이터 유효성 검사 ([데이터] → 데이터 도구)

  • 입력할 수 있는 데이터의 형식과 범위를 제한 (예: 1~100 정수만)
  • 제한 대상: 모든 값, 정수, 소수점, 목록, 날짜, 시간, 텍스트 길이, 사용자 지정 (“텍스트”는 없음)
  • 목록: 원본 값을 쉼표(,)로 구분해 직접 입력(남,여) / 셀 범위 지정 / 이름 사용(=판정)
    → 드롭다운 목록의 너비는 셀 너비에 따라 결정 (따로 지정 불가)
  • 탭: 설정, 설명 메시지, 오류 메시지(스타일: 중지·경고·정보)
  • 해제: 범위 선택 → 유효성 검사 → 모두 지우기
  • 함정: “목록 값은 세미콜론으로 구분” ✗ · “드롭다운 너비 지정 가능” ✗

1-7. Part 1 시험 포인트

  • Ctrl+` 수식 표시, 중첩 함수 64개, 범위는 콜론·구분은 쉼표
  • F4 참조 전환, $가 붙은 쪽은 고정
  • 다른 시트 = 시트명!셀, 공백·숫자 시트명 = '작은따옴표', 다른 파일 = [대괄호]
  • #DIV/0! 0 나누기, #NAME? 이름 오타, #REF! 참조 삭제, #VALUE! 숫자+문자, #NULL! 공백, #N/A 값 없음
  • 이름: 255자, 공백 불가, 대소문자 구분 안 함, 절대 참조
  • 유효성 검사: 텍스트 길이, 목록은 쉼표 구분, 너비는 셀 너비

Part 2. 조건부 서식 · 텍스트 나누기 · 중복 제거 · 데이터 가져오기

2-1. 조건부 서식 ([홈] → 스타일 → 조건부 서식)

  • 셀 값이나 수식이 조건을 만족하면 자동으로 서식 적용
  • 메뉴: 셀 강조 규칙, 상위/하위 규칙, 데이터 막대, 색조, 아이콘 집합, 새 규칙, 규칙 지우기, 규칙 관리
  • 수식 사용 시: 새 규칙 → “수식을 사용하여 서식을 지정할 셀 결정”, 수식은 =로 시작
  • 행 전체에 적용하려면 열만 고정한 혼합 참조 (=$D2<3) → 셀을 클릭하면 절대 참조가 되므로 F4를 두 번
  • 조건부 서식에서 지정할 수 있는 서식: 표시 형식, 글꼴, 테두리, 채우기 (맞춤·보호 없음)
  • 데이터가 바뀌면 조건부 서식도 자동으로 다시 적용·해제
  • 여러 규칙이 충돌하면 규칙 관리자 목록의 위쪽 규칙이 우선 (순서 변경 가능), 규칙 편집·삭제는 규칙 관리, 일괄 삭제는 규칙 지우기(선택한 셀 / 시트 전체)
  • 중복 값 규칙: 고유(한 번만 나오는 값) / 중복(두 번 이상 나오는 값)
  • 함정: “여러 조건을 동시에 만족하면 가장 나중에 만족한 조건의 서식 적용” ✗
예제수식
대출 금액(B열)이 평균보다 크면 행 전체 파랑=$B2>AVERAGE($B$2:$B$6)
평점(D열)이 3.0 미만이면 행 전체 채우기=$D2<3
짝수 행에만 서식=MOD(ROW(),2)=0

※ ROW() = 행 번호, COLUMN() = 열 번호, MOD(수, 나눌 수) = 나머지. (강의에서 ROW·COLUMN 설명이 한 번 뒤바뀌어 바로잡았습니다.)

2-2. 텍스트 나누기 ([데이터] → 데이터 도구)

  • 한 셀에 들어 있는 텍스트를 여러 열로 분리. 마법사 3단계
  • 1단계: 구분 기호로 분리됨 / 너비가 일정함(구분선을 클릭해 위치 지정)
  • 2단계 구분 기호: 탭, 세미콜론, 쉼표, 공백, 기타 — 두 개 이상의 구분 기호를 함께 사용 가능
  • 3단계: 열 데이터 서식 지정, 열 가져오지 않음 선택 가능
  • 함정: “구분 기호가 두 가지 이상이면 텍스트 나누기 불가” ✗

2-3. 중복된 항목 제거 · 데이터 가져오기

  • 중복된 항목 제거([데이터] → 데이터 도구): 체크한 열의 값이 같으면 중복으로 보고 하나만 남김
    예) 날짜만 체크 → 같은 날짜는 하나만 / 날짜와 품목 모두 체크 → 둘 다 같은 행만 제거
  • 데이터 가져오기: 텍스트, 웹, HTML, 데이터베이스(Access 등), XML 가능 · 한글(HWP), MS Word 파일은 불가

2-4. Part 2 시험 포인트

  • 조건부 서식 메뉴 5가지: 셀 강조·상위/하위·데이터 막대·색조·아이콘 집합
  • 행 전체 = 열 고정 혼합 참조($D2), 서식은 표시 형식·글꼴·테두리·채우기
  • 규칙 충돌 시 위쪽 규칙 우선, 데이터가 바뀌면 자동 재적용
  • 텍스트 나누기: 구분 기호 / 너비 일정, 구분 기호 여러 개 가능
  • 가져오기 불가 = 한글, Word

Part 3. 자동 필터 · 고급 필터 · 찾기/바꾸기

3-1. 자동 필터 ([데이터] → 정렬 및 필터 → 필터)

  • 목록 단추(▼)로 조건에 맞는 행만 표시, 나머지는 숨김 → 원래 위치에서만 필터링 (다른 곳에 복사 불가)
  • 필터 해제(지우기)하면 모든 데이터가 다시 표시. 필터를 쓰려고 미리 정렬할 필요 없음
  • 문자 열 → 텍스트 필터, 숫자 열 → 숫자 필터, 사용자 지정 필터(그리고 / 또는)
  • 같은 열: AND·OR 모두 가능 / 서로 다른 열: AND만 가능 (OR 불가)
  • 예: “판매 수량 100 이상 그리고 200 이하”(같은 열) ✓ · “주소가 서울이거나 직업이 학생”(다른 열 OR) ✗

3-2. 와일드카드 문자

입력의미
컴활*컴활로 시작하는 모든 글자 (글자 수 제한 없음)
*컴활컴활로 끝나는 모든 글자
*컴활*컴활이 포함된 모든 글자
김??김으로 시작하는 세 글자 (? = 한 글자)
?경?가운데가 경인 세 글자
?영*두 번째 글자가 영인 데이터
  • 함정: 사용자 지정 필터 “박으로 시작 또는 ??” → 박으로 시작하는 모든 이름 + 두 글자 이름 (박으로 시작하는 두 글자가 아님)

3-3. 고급 필터 ([데이터] → 정렬 및 필터 → 고급)

  • 조건을 워크시트에 직접 입력해서 필터링, 결과를 현재 위치 또는 다른 장소에 복사 가능
  • 대화상자: 목록 범위, 조건 범위, 복사 위치(다른 장소일 때), 동일한 레코드는 하나만
  • 조건 범위: 필드명 포함 표 형태, 필드명은 원본과 똑같이 (=셀 참조로 가져오면 정확), 와일드카드 사용 가능
  • 같은 행 = AND(이고, 이면서), 다른 행 = OR(이거나)
  • 고급 필터 결과를 정렬해도 숨겨진 레코드는 정렬되지 않음
성별평균
여>=60

AND: 성별이 여이고 평균 60 이상

성별평균
여
>=60

OR: 성별이 여이거나 평균 60 이상

성명부서점수
*명
영업>80

혼합: 명으로 끝나거나, (영업이면서 80 초과)

3-4. 고급 필터의 수식 조건 (필기 단골)

  • 조건에 함수(수식)를 쓸 때는 필드명을 원본 필드명과 다르게 (예: 평균, 조건) 또는 비워 둠
  • 수식은 =로 시작, 결과는 TRUE/FALSE로 표시
  • 비교 대상(첫 데이터 셀)은 상대 참조, 평균을 구할 전체 범위는 절대 참조
  • 예) 판매 수량이 평균 이상: 필드명 평균, 조건 =B2>=AVERAGE($B$2:$B$8)
  • 예) 영어 점수가 평균 초과이면서 성명 두 번째 글자가 영:
    필드명 성명 | 영어평균 → ?영* | =D2>AVERAGE($D$2:$D$9) (같은 행)

3-5. 찾기 / 바꾸기

  • 찾기 Ctrl + F (또는 Shift + F5), 바꾸기 Ctrl + H, [홈] → 편집 → 찾기 및 선택
  • 범위: 시트 / 통합 문서 · 검색: 행 / 열 · 찾는 위치: 수식, 값, 메모
  • 옵션: 대/소문자 구분, 전체 셀 내용 일치, 전자/반자 구분, 서식(숫자 셀 포함 서식 찾기·바꾸기 가능)
  • 와일드카드(*, ?) 사용 가능. 와일드카드 문자 자체를 찾으려면 앞에 물결(~): ~* ~? ~~
  • Shift를 누른 채 [다음 찾기] → 이전 항목 찾기 · [모두 찾기] → 조건에 맞는 모든 항목 나열
  • 바꾸기: 내용과 서식까지 한꺼번에 바꿀 수 있음 (모두 바꾸기)
  • 함정: “메모 안의 텍스트는 찾을 수 없다” ✗ · “숫자 셀은 서식 찾기에서 제외” ✗

3-6. Part 3 시험 포인트

  • 자동 필터: 원래 위치에서만, 같은 열 AND/OR, 다른 열 AND만, 정렬 필요 없음
  • * 여러 글자, ? 한 글자, ~ 와일드카드 자체 찾기
  • 고급 필터: 같은 행 AND, 다른 행 OR, 다른 장소 복사 가능
  • 수식 조건: 필드명은 원본과 다르게, 평균 범위는 절대 참조
  • 찾기 Ctrl+F, 바꾸기 Ctrl+H, 찾는 위치 = 수식·값·메모

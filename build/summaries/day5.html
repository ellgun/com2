Part 1. 네트워크

1-1. 네트워크 운영 방식

방식특징
중앙 집중 방식모든 데이터 처리·관리를 하나의 중앙 컴퓨터(서버)가 담당
피어 투 피어(P2P)
= 동배간 처리		모든 컴퓨터가 서버이자 클라이언트. 서버 없이 자원 공유, 소규모 네트워크에 적합 (예: 메신저로 직접 파일 주고받기)
클라이언트/서버요청하는 클라이언트와 제공하는 서버가 명확히 분리(손님과 주방). 분산 처리에 적합, 보안 관리 쉬움. 서버 구축·유지 비용, 서버 장애 시 서비스 중단

1-2. 통신망의 종류

통신망설명
LAN (근거리)건물·회사 등 좁은 지역. 설치 간단, 보안 쉬움, 전송 속도 빠름
MAN (도시권)도시 규모 지역 연결 (LAN보다 넓고 WAN보다 좁음)
WAN (광역)국가·대륙 간 넓은 지역 연결
VAN (부가가치 통신망)통신 회선에 정보 서비스를 더한 통신망 (예: 카드 결제 중계망). 회선을 보유하거나 임차해 사용
ISDN (종합정보통신망)전화·팩스·데이터를 하나의 회선으로 통합해 전송
B-ISDN (광대역)ISDN보다 고속·광대역, 멀티미디어 전송, 디지털 방식
  • 크기 순서: WAN > MAN > LAN
  • 함정: “B-ISDN은 아날로그 방식” ✗ (디지털)
  • 무선 LAN 구성 요소(최근 출제): 단말기, 브리지, 랜카드, 안테나, AP(액세스 포인트) — 리피터는 해당 안 됨

1-3. 통신 방식

방식설명예
단방향한쪽으로만 전송라디오, TV
반이중양방향 가능하지만 동시에는 불가무전기
전이중양방향 동시 송수신전화

1-4. 네트워크 구성 형태 (그림으로도 출제)

형태특징
성형(스타형)중앙 허브·스위치에 각 컴퓨터 연결. 설치·확장 쉬움, 중앙 장치 고장 시 전체 마비
트리형(계층형)성형을 여러 계층으로 확장한 나뭇가지 모양. 대규모 관리 유리, 상위 노드 고장 시 하위 영향
링형(환형)원 모양, 데이터가 한 방향으로 순환. 충돌 적음, 한 곳 고장 시 전체 영향
버스형하나의 공통 케이블에 여러 장치 연결. 설치 간단·비용 적음·추가 삭제 쉬움, 충돌 잦음, 기밀성 낮음, 회선 길이 제한
망형(메시형)모든 노드가 서로 직접 연결. 장애 시 우회 경로 → 신뢰성 가장 높음, 설치 비용·관리 복잡
  • 함정: “버스형은 기밀 보장이 우수하고 회선 길이 제한이 없다” ✗

1-5. OSI 7계층과 장비

  • ISO가 제정한 네트워크 통신 규약. 순서: 물리 → 데이터 링크 → 네트워크 → 전송 → 세션 → 표현 → 응용 (특히 2·3·4계층이 자주 출제)
계층역할장비
1 물리전송 매체의 전기적·물리적 특성 규정리피터, 허브, 케이블
2 데이터 링크오류 검출, 프레임 단위 전송브리지, 스위치
3 네트워크경로 설정라우터
4 전송신뢰성 있는 전송, 포트 번호, 오류 복구게이트웨이
5~7세션 · 표현 · 응용—
  • 함정: “OSI 3계층은 데이터 링크” ✗ (네트워크)

1-6. 네트워크 장비 (키워드로 찾기)

장비키워드
라우터IP 주소 기준 최적의 경로를 찾아 다른 네트워크로 전달
리피터신호를 재생·증폭해 장거리 전송
브리지같은 프로토콜을 쓰는 LAN과 LAN을 연결(다리)
게이트웨이다른 네트워크로 들어가는 출입구(문)
허브여러 컴퓨터를 연결해 회선을 통합 관리
DNS도메인 이름 ↔ IP 주소 변환
모뎀디지털 ↔ 아날로그 신호 변환
  • 함정: “브리지는 디지털 신호를 아날로그로 변환” ✗ (모뎀)

1-7. 네트워크 명령어 (명령 프롬프트 cmd)

명령어기능
ipconfig내 IP 주소, 서브넷 마스크, 기본 게이트웨이 확인
tracert목적지 서버까지의 경로 추적
pingIP·도메인에 접속 가능한지, 왕복 시간 확인

1-8. 프로토콜

  • 서로 다른 컴퓨터가 통신하기 위해 약속한 규칙. 기능: 흐름 제어, 동기화, 오류 제어
프로토콜키워드
TCP데이터를 패킷으로 나눠 전송, 흐름·오류 제어 (전송 계층) — 인터넷 기본 규약 TCP/IP
IP주소 지정, 경로 설정 (네트워크 계층)
HTTP웹 서버와 브라우저 사이 하이퍼텍스트(HTML) 전송
DHCPIP 주소를 자동(동적)으로 할당
FTP파일 업로드·다운로드 (원격 파일 전송)
ARPIP 주소로 물리 주소(MAC 주소) 찾기
ICMP네트워크 상태 점검·오류 전달, ping에 사용
SNMP라우터·스위치 등 네트워크 장비 관리
WAP무선 인터넷 규약
TELNET원격으로 다른 컴퓨터 접속·조작
  • FTP: 사이트 계정이 필요, 업로드·다운로드·삭제·이름 변경 가능, 바이너리·ASCII 모드 제공. 함정: “FTP 서버의 응용 프로그램을 바로 실행할 수 있다” ✗ (다운로드 후 실행)

1-9. 전자우편 프로토콜 (4가지 모두 중요)

프로토콜역할
SMTP메일 보내기
POP3메일 받기 (서버에서 내 컴퓨터로 가져오기)
MIME이미지·오디오·영상·첨부 파일 등 멀티미디어 메일
IMAP메일을 서버에 남겨 둔 채 읽고 관리·검색, 여러 기기에서 접근
  • 전자우편 주소: 아이디@도메인 · 여러 사람에게 동시 발송 가능
  • 전달(Forward) = 받은 메일을 다른 사람에게 그대로 보내기 / 회신(Reply) = 보낸 사람에게 답장. 함정: 답장을 “전달”이라고 한 보기 ✗

1-10. Part 1 시험 포인트

  • P2P = 서버이자 클라이언트, 클라이언트/서버 = 역할 분리·분산 처리
  • VAN = 서비스 추가, ISDN = 하나의 회선으로 통합, B-ISDN = 고속·디지털
  • 성형 = 중앙 고장 시 전체 마비, 망형 = 신뢰성 최고
  • OSI: 물리-리피터, 데이터링크-브리지, 네트워크-라우터, 전송-게이트웨이
  • ipconfig = IP 확인, tracert = 경로 추적, ping = 접속 확인
  • DHCP = IP 자동 할당, FTP = 파일 전송, SMTP 보내기 / POP3 받기

Part 2. 인터넷

2-1. 인터넷 관련 용어

용어설명

캐싱방문한 웹 페이지 정보를 임시 저장했다가 다음 접속 때 빠르게 표시

즐겨찾기(북마크) · 히스토리자주 가는 주소 저장 / 방문 기록
미러 사이트접속자가 많거나 먼 곳의 속도 저하를 막으려고 원본과 같은 내용을 허가하에 복제한 사이트
링크 사이트자체 콘텐츠 없이 다른 사이트로 연결해 주는 사이트

인트라넷회사·기관 내부 전용 네트워크

서비스설명

2-3. 최신 IT 기술

기술설명
IoT (사물 인터넷)사물·사람·공간을 인터넷으로 연결해 데이터를 수집·분석·판단하고 지능화된 서비스를 자율 제공
빅데이터대용량·다양성·고속으로 생성되는 방대한 데이터와 그 분석 기술
메타버스가상과 현실이 융합된 3차원 공간에서 아바타로 활동
블록체인거래 기록을 여러 컴퓨터에 분산 저장해 위·변조 방지
AI · ChatGPT인간의 학습·판단 능력을 모방 / OpenAI의 대화형 언어 모델
유비쿼터스언제 어디서나 네트워크에 접속할 수 있는 환경
RFID무선 주파수로 사물에 붙은 전자 태그 정보를 비접촉 인식 (출입 통제, 도서 대출)
NFC10cm 이내 근거리 무선 통신 (모바일 결제, 교통카드)
USN센서로 정보를 수집해 네트워크로 실시간 전송·관리 (스마트팜, 산불·홍수 감지)
텔레매틱스차량에 정보통신을 접목 (교통·위치·긴급 구조)
  • 함정: “IoT는 통신 비용이 절감되고 보안 적용이 쉽다” ✗ (통신 비용 증가, 보안이 아직 과제)

2-4. IP 주소: IPv4 vs IPv6 (IPv6 자주 출제)

구분IPv4IPv6
길이32비트128비트
표기8비트씩 4부분, 점(.)으로 구분16비트씩 8부분, 16진수, 콜론(:)으로 구분
클래스A~E 클래스클래스 구분 없음

  • 함정: “IPv6는 8비트씩 16부분” ✗ · “IPv6는 A~E 클래스” ✗ · 현재는 IPv4와 IPv6를 함께 사용하며 점차 IPv6로 전환 중

2-5. 도메인 · DNS · URL

  • 도메인 네임: 숫자 IP 주소를 사람이 기억하기 쉬운 문자로 표현. 전 세계에서 유일. 도메인 ≠ IP 주소 (DNS가 변환)
  • 관리 기관: 한국 KISA(한국인터넷진흥원), 국제 ICANN
  • 함정: “인터넷은 중앙 통제 기구(인터닉)가 운영” ✗

2-6. Part 2 시험 포인트

  • 쿠키 = 자동 로그인, 미러 사이트 = 허가하에 복제, 인트라넷 = 내부 / 엑스트라넷 = 협력사
  • VoIP 인터넷 전화, mVoIP 무선망, VPN 암호화 터널, LBS 위치 기반, 테더링 = 스마트폰 공유

  • KISA / ICANN, kg 유치원 · es 초등 · hs 고등

Part 3. 바이러스와 정보 보안

3-1. 바이러스 예방

  • 방화벽 설치, 최신 백신 사용·주기적 검사
  • 출처가 불분명한 메일은 열지 않고 바로 삭제 (“열어 보고 삭제”, “본문 확인 후 삭제” ✗)
  • 네트워크 공유 폴더는 읽기 전용, 다운로드한 파일은 실행 전 검사
  • 함정: “첨부 파일을 다른 이름으로 저장해 사용한다”는 예방법이 아님

3-2. 악성 프로그램 종류

종류한 줄 정리설명
웜자기 복제스스로 복제해 네트워크로 퍼지며 시스템을 느리게·다운. 예: DDoS, 버퍼 오버플로, 슬래머
트로이 목마숨어서 실행정상 프로그램으로 위장, 실행되면 악성 행위. 자기 복제 능력 없음
랜섬웨어금전 요구파일을 암호화하고 복구 대가로 돈 요구

  • 함정: 웜의 형태가 아닌 것 = 트로이 목마

3-3. 방화벽 · 프록시 서버

  • 방화벽: 외부와 내부 네트워크 사이에서 외부의 불법 접근·해킹을 차단. 허가된 사용자만 접속, 안전한 통신, 로그로 침입 역추적 가능
  • 방화벽의 한계: 내부 사용자의 불법 행위는 막지 못함, 메일 바이러스·피싱·악성 코드 감염 차단 어려움
  • 함정: “방화벽이 바이러스 감염을 인지해 알려 준다” ✗ (백신의 역할)
  • 프록시 서버: 클라이언트와 인터넷 서버 사이의 중계(대리) 서버. 캐시 + 방화벽 기능 → 내 IP를 숨겨 보안 강화, 자주 쓰는 정보 저장으로 속도 향상

3-4. 정보 사회의 역기능

  • 정보 범죄 증가, 유해 정보 확산, 개인 정보 침해, 인터넷 중독, 정보 격차 심화, 서버 장애로 인한 사회적 혼란
  • 건강 문제: 테크노 스트레스(새 기술에 적응하지 못해 생기는 정신적 스트레스), VDT 증후군(장시간 사용으로 목·어깨·허리 통증, 시력 저하)
  • 함정: “정보 편중으로 계층 간 정보 차이를 줄일 수 있다” ✗
  • 예방: 비밀번호 주기적 변경, 백신 자동 업데이트, Windows 업데이트 자동 설치, 정크 메일(스팸)은 본문 확인 없이 즉시 삭제

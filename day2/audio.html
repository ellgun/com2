컴퓨터 활용능력 2급 필기 2일차 음성 강의입니다. 컴퓨터 일반 과목에서 파일 탐색기, 윈도우 설정, 관리 도구, 장치 관리자, 작업 관리자를 순서대로 살펴보겠습니다.

먼저 파일 탐색기입니다. 파일 탐색기는 컴퓨터 안의 자료를 한눈에 보고 정리하는 프로그램입니다. 서류 정리함이라고 생각하시면 쉽습니다. 실행은 윈도우 키와 E를 함께 누르면 됩니다. 화면은 왼쪽의 탐색 창과 오른쪽의 내용 창으로 나뉩니다. 폴더 앞의 기호가 접힌 모양이면 하위 폴더가 숨겨져 있다는 뜻이고, 펼쳐진 모양이면 하위 폴더가 보이고 있다는 뜻입니다.

파일 탐색기에서 키보드 조작도 꼭 기억하세요. 숫자 키패드의 별표를 누르면 선택한 폴더의 하위 폴더가 모두 펼쳐집니다. 더하기는 펼치기, 빼기는 접기입니다. 상위 폴더로 올라갈 때는 백스페이스를 누릅니다. 글자를 지우는 키가 아니라는 점에 주의하세요. 파일 검색은 F3입니다.

이동과 복사는 시험에 자주 나오는 내용입니다. 같은 드라이브 안에서 파일을 끌어다 놓으면 이동됩니다. 같은 드라이브에서 복사하려면 Ctrl 키를 누른 채 끌어다 놓습니다. 다른 드라이브 사이에서는 반대입니다. 그냥 끌어다 놓으면 복사되고, 이동하려면 Shift 키를 누릅니다. Alt 키를 누른 채 끌어다 놓으면 이동이 아니라 바로 가기 아이콘이 만들어집니다.

파일을 선택할 때는 연속된 파일이면 Shift, 떨어져 있는 파일이면 Ctrl을 씁니다. 폴더 안의 모든 파일을 선택하려면 Ctrl과 A를 누릅니다. Alt와 A가 아니라는 점을 기억하세요.

폴더 옵션은 파일 탐색기의 파일 탭에서 옵션을 눌러 들어갑니다. 탭은 세 개입니다. 일반 탭에서는 폴더를 같은 창에서 열지 새 창에서 열지, 한 번 클릭할지 두 번 클릭할지, 기록을 지울지 기본값으로 되돌릴지를 정합니다. 보기 탭에서는 숨김 파일을 보일지, 확장자를 숨길지, 전체 경로를 표시할지를 정합니다. 검색 탭에서는 하위 폴더나 압축 파일을 검색에 포함할지를 정합니다. 숨김 속성을 한꺼번에 해제하는 기능은 없습니다. 보기 탭에서는 숨김 항목을 화면에 보이게 할지만 정할 수 있습니다.

다음은 보조 프로그램입니다. 메모장은 서식 없는 텍스트 편집기이고, 저장하면 확장자가 txt로 붙습니다. F5를 누르면 현재 날짜와 시간이 들어갑니다. 메모장에서는 그림이나 차트 같은 개체를 넣을 수 없고, 글자 일부만 골라서 서식을 바꾸는 것도 안 됩니다. 문서 전체의 글꼴이나 크기는 바꿀 수 있습니다.

스티커 메모는 바탕 화면에 메모를 띄워 두는 프로그램입니다. 색을 바꾸고, 굵게나 기울임 같은 간단한 서식을 쓰고, 그림을 넣을 수 있습니다. 머리글과 바닥글은 넣을 수 없습니다. 그림판은 비트맵 방식의 그림을 그리는 프로그램이고, 다른 프로그램과 연결하는 OLE 기능을 지원합니다. 시프트 키를 누르고 그리면 정원이나 정사각형을 쉽게 그릴 수 있습니다.

캡처 도구는 화면의 일부나 전체를 캡처합니다. 저장 형식은 PNG, JPG, GIF 세 가지입니다. 단축키는 윈도우 키, 시프트, S입니다. 윈도우 미디어 플레이어는 재생 프로그램입니다. CD 재생이나 복사, 인터넷 라디오는 가능하지만 동영상을 편집하는 기능은 없습니다. 실행 창은 윈도우 키와 R이고, 명령 프롬프트는 실행 창에 cmd를 입력해서 엽니다.

이제 윈도우 설정입니다. 설정 창은 윈도우 키와 I를 누르면 바로 열립니다. 시작 단추를 누르고 설정을 선택해도 됩니다.

설정에서 앱 항목은 설치된 앱을 확인하고 제거하거나, 음악이나 사진 같은 파일 형식별로 기본 앱을 정하는 곳입니다. 오프라인 지도와 시작 프로그램도 여기에 있습니다. 삭제된 프로그램 파일을 복원하는 기능은 앱 설정에 없습니다.

시스템 항목에서 디스플레이는 모니터 감지, 해상도, 화면 방향, 배율, 글자 크기를 정하는 곳입니다. 여러 모니터를 확장할지 복제할지도 여기서 정합니다. 정보 항목에서는 PC 이름, CPU와 메모리 같은 사양, 윈도우 버전을 확인합니다. 정품 인증은 정보가 아니라 업데이트 및 보안에서 합니다.

개인 설정에서는 배경, 잠금 화면, 테마, 글꼴을 바꿉니다. 잠금 화면에서는 화면 시간 제한과 화면 보호기를 설정할 수 있습니다. 테마는 배경, 색, 소리, 마우스 커서를 한 묶음으로 바꾸는 기능입니다. 인터넷에서 받은 글꼴은 압축을 풀고 글꼴 항목에 설치해야 한글이나 엑셀에서 쓸 수 있습니다. 해상도는 개인 설정이 아니라 디스플레이에서 바꿉니다. 바탕 화면 가젯은 윈도우 7까지 지원되던 기능이라 지금은 없습니다.

접근성은 윈도우 키와 U를 누르면 열립니다. 시력, 청력, 움직임에 어려움이 있는 사용자를 위한 기능들입니다. 돋보기는 윈도우 키와 더하기로 실행하고, 윈도우 키와 Esc로 끕니다. 확대는 더하기, 축소는 빼기입니다. 돋보기에는 세 가지 보기 방식이 있습니다. 전체 화면은 화면 전체를 확대합니다. 렌즈 모드는 마우스 포인터 주변만 확대합니다. 도킹 모드는 화면의 한쪽에 확대 영역을 따로 보여 줍니다. 포인터 주변을 확대하는 것은 렌즈 모드입니다. 내레이터는 글자뿐 아니라 버튼이나 메뉴 같은 화면 요소까지 소리로 읽어 줍니다.

마우스 설정은 두 곳에 있습니다. 장치 설정의 마우스에서는 왼손잡이용 단추 바꾸기, 두 번 클릭 속도, 포인터 모양, 포인터 이동 속도를 정합니다. 접근성의 마우스에서는 숫자 키패드로 포인터를 움직이는 기능을 설정합니다.

계정 설정에서는 로그인 방식과 가족 구성원 추가를 관리합니다. 계정은 표준 계정과 관리자 계정으로 나뉩니다. 표준 계정은 대부분의 프로그램을 쓸 수 있지만, 컴퓨터 보안에 영향을 주는 설정은 바꿀 수 없습니다. 관리자 계정은 모든 설정을 바꿀 수 있고, 다른 계정을 관리하며, 모든 파일과 프로그램에 접근할 수 있습니다. 표준 계정도 자신의 암호는 바꿀 수 있습니다. 관리자가 설정한 프린터를 지우는 것은 표준 계정이 할 수 없습니다.

마지막으로 업데이트 및 보안입니다. 업데이트를 최대 35일까지 일시 중지할 수 있습니다. 정품 인증, 백업, 복구도 여기서 합니다. 복구에는 초기화만 있는 것이 아닙니다. 시스템 복원이나 고급 시작 옵션 같은 방법도 있으니 문제가 생겼다고 바로 초기화할 필요는 없습니다.

이제 관리 도구입니다. 디스크 검사는 하드디스크의 오류를 찾아 고치고 복구합니다. CD롬과 네트워크 드라이브는 검사할 수 없습니다. 디스크 정리는 불필요한 파일을 지워서 사용할 수 있는 용량을 늘립니다. 대상은 휴지통 파일, 임시 파일, 다운로드한 파일, 임시 인터넷 파일입니다. 글꼴 파일은 디스크 정리 대상이 아닙니다.

드라이브 최적화, 흔히 조각 모음이라고 부르는 기능은 흩어진 파일 조각을 모아서 속도를 높입니다. 용량을 늘리는 기능이 아니라는 점이 중요합니다. USB나 외장 하드는 조각 모음이 가능하지만, CD롬과 네트워크 드라이브는 불가능합니다. 예약 실행도 설정할 수 있습니다. 실행 방법은 C 드라이브를 우클릭해서 속성을 열고, 도구 탭에서 최적화를 누르는 것입니다. 정리는 용량을 늘리고, 최적화는 속도를 높인다. 이것만 기억하셔도 시험에서 헷갈리지 않습니다.

디스크 포맷은 저장 장치의 구조를 초기화하는 작업입니다. 용량, 파일 시스템, 할당 단위 크기를 확인할 수 있고, 볼륨 레이블이라는 드라이브 이름도 지정할 수 있습니다.

다음은 파일 시스템입니다. 파일 시스템은 운영 체제가 저장 장치에 데이터를 어떤 방식으로 저장하고 관리할지 정한 규칙입니다. FAT 계열은 여러 운영 체제에서 호환성이 좋지만 저장 가능한 용량이 4기가바이트 이하입니다. 그래서 주로 USB 같은 이동식 장치에 씁니다. exFAT는 FAT를 개선해서 큰 용량을 저장할 수 있지만, 안정성은 NTFS보다 낮습니다. NTFS는 윈도우의 기본 파일 시스템입니다. 안정성이 뛰어나고 대용량을 지원하며, 보안, 압축, 복구 기능을 지원합니다. 보안 기능처럼 고급 기능이 필요하면 NTFS를 선택합니다. 시스템 리소스 설명에서는 최대화가 아니라 최소화라는 점을 기억하세요. 참고로 VFS는 리눅스에서 여러 파일 시스템을 묶을 때 쓰는 가상 형식이며, 실제 디스크를 포맷하는 형식이 아닙니다.

장치 관리자는 컴퓨터의 하드웨어 목록과 작동 상태를 확인하고, 드라이버를 관리하는 도구입니다. 시작 단추를 우클릭하면 들어갈 수 있습니다. 장치 옆의 노란 물음표는 드라이버가 설치되지 않았다는 뜻입니다. 노란 느낌표는 장치가 정상적으로 작동하지 않는다는 뜻입니다. X 표시는 장치가 사용되지 않고 있다는 뜻입니다. 하드웨어에 문제가 있으면 드라이버를 업데이트해서 해결할 수 있습니다.

작업 관리자는 실행 중인 앱과 프로세스, 시스템 성능을 확인하는 도구입니다. 시작 단추를 우클릭하거나 Ctrl, Shift, Esc를 함께 누르면 열립니다. 프로세스 탭에서는 실행 중인 앱과 백그라운드 프로세스를 보고, 응답하지 않는 프로그램을 작업 끝내기로 강제 종료할 수 있습니다. 성능 탭에서는 CPU, 메모리, 디스크, 이더넷 사용량을 확인합니다. 앱 기록 탭에서는 앱별 CPU 사용 시간과 네트워크 정보를 볼 수 있습니다. 실행 중인 프로그램의 순서는 바꿀 수 없습니다. 필수 윈도우 프로세스를 끝내면 시스템이 불안정해질 수 있으니 주의하세요.

마지막은 레지스트리입니다. 레지스트리는 윈도우의 환경 설정과 시스템 정보를 계층 구조로 기록한 데이터베이스입니다. 실행 창에 regedit를 입력하면 레지스트리 편집기가 열립니다. 잘못 편집하면 시스템에 심각한 문제가 생기고 데이터가 손실될 수 있습니다. 그러니 편집하기 전에 반드시 백업해야 합니다. 잘못 편집해도 데이터 손실은 막을 수 있다는 설명은 틀린 내용입니다.

정리하겠습니다. 용량을 늘리려면 디스크 정리, 속도를 높이려면 조각 모음과 최적화입니다. 4기가바이트 제한은 FAT, 보안과 안정성은 NTFS입니다. 물음표는 미설치, 느낌표는 비정상 작동, X는 사용 안 함입니다. 설정은 윈도우 키와 I, 접근성은 윈도우 키와 U, 돋보기는 윈도우 키와 더하기입니다. 오늘 강의는 여기까지입니다. 수고하셨습니다.

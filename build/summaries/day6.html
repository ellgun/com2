Part 1. 통합 문서 · 워크시트 · 화면 구성

1-1. 통합 문서

  • 엑셀 파일 하나 = 통합 문서(워크북). 기본 확장자 .xlsx. 새 문서는 통합 문서1, 2, 3… 순으로 이름이 붙음
  • 통합 문서 안에 워크시트가 여러 개, 워크시트는 셀로 구성. 시트는 최소 1개 있어야 함
  • 여러 통합 문서를 동시에 열 수 있음 (메모리 성능에 따라 느려질 수 있음)
단축키기능
Ctrl + N새 통합 문서
Ctrl + O열기
Ctrl + S저장
Ctrl + F4 / Ctrl + W통합 문서 창 닫기
Shift + F11새 워크시트 삽입

1-2. 저장 시 일반 옵션 (다른 이름으로 저장 → 도구 → 일반 옵션)

옵션설명
백업 파일 항상 만들기저장할 때마다 백업 파일 자동 생성, 확장자 .xlk
열기 암호암호를 알아야 파일을 열 수 있음 (모르면 못 엶)
쓰기 암호파일은 열 수 있지만 수정 후 같은 이름으로 저장하려면 암호 필요. 모르면 읽기 전용으로 열기 가능, 다른 이름으로 저장은 가능
읽기 전용 권장암호가 아님. 열 때 읽기 전용으로 열지 예/아니요를 묻는 메시지만 표시
  • 함정: “쓰기 암호가 있으면 다른 이름으로 저장할 때도 암호 필요” ✗

1-4. 워크시트 · 시트 다루기

  • 셀 = 행(1, 2, 3…)과 열(A, B, C…)이 만나는 곳. 셀 주소 예: D열 6행 → D6
  • 시트 선택: 떨어진 시트 Ctrl+클릭, 연속된 시트 Shift+클릭, 바로 가기 메뉴 → 모든 시트 선택
  • 여러 시트를 선택하면 제목 표시줄에 [그룹] 표시 → 이때 입력한 내용은 선택된 모든 시트에 똑같이 입력
  • 시트 이름 바꾸기: 더블클릭 또는 바로 가기 메뉴. 공백 포함 최대 31자, 공백 사용 가능, \ / ? * [ ] 사용 불가
  • 시트 이동: 시트 탭을 드래그 / 복사: Ctrl+드래그 → “시트명 (2)”처럼 번호가 붙음. 다른 통합 문서로도 이동·복사 가능
  • 시트 삭제는 실행 취소(Ctrl+Z)로 되살릴 수 없음 (내용이 있으면 영구 삭제 경고)
  • 탭 색: 시트 구분용, 꼭 다른 색으로 지정할 필요 없음 · 숨기기 / 숨기기 취소 가능
  • 새 통합 문서의 기본 시트 수는 엑셀 옵션에서 지정(최대 255), 실제 시트 수는 메모리에 따라 제한

1-6. Part 1 시험 포인트

  • xlk 백업, xltx 서식, xlsm 매크로, xltm 매크로 서식 / txt 탭 · prn 공백 · csv 쉼표

Part 2. 시트 보호 · 데이터 입력

2-1. 시트 보호 · 통합 문서 보호 ([검토] 탭 → 보호 그룹)

구분시트 보호통합 문서 보호
대상셀의 내용 입력·수정 제한시트 구조: 삽입·삭제·이동·복사·숨기기·이름 바꾸기 금지
(창 선택 시 창 이동·크기 조정·닫기 금지)
암호선택 사항 (없어도 보호 가능, 단 누구나 해제 가능)
  • 셀 서식 → [보호] 탭: 새 시트의 모든 셀은 기본으로 잠금 ✓, 숨김 ✗
  • 시트 보호가 적용되려면 셀에 잠금이 설정되어 있어야 함 (잠금 해제된 셀은 보호 안 됨)
  • 숨김을 설정하고 시트를 보호하면 수식 입력줄에 수식이 표시되지 않음 (값은 보임)
  • 잠금·숨김 속성은 시트를 보호하기 전까지는 아무 효과 없음 · 보호된 셀을 수정하면 경고 메시지
  • 차트 시트는 차트 내용만 변경 못 하게 보호 가능
  • 함정: “셀을 보호하려면 먼저 잠금을 해제해야 한다” ✗ · “보호하려면 숨김을 선택해야 한다” ✗ · “암호는 필수” ✗

2-2. 데이터 종류별 입력

종류정렬입력 방법·특징
문자왼쪽한글·영문·숫자+문자 조합. 셀보다 길면 옆 셀로 이어서 표시, 옆 셀에 내용이 있으면 잘림
숫자를 문자로 입력: 앞에 작은따옴표(') (예: '002)
특수 문자: 한글 자음(ㅁ 등) + 한자 키 · 한자: 범위 지정 후 한자 키
숫자오른쪽음수는 앞에 - 또는 괄호. 분수는 0 + 공백 + 분수 (예: 0 2/5)
너무 길면 지수 형식 또는 #### (열 너비를 넓히면 정상 표시)
숫자에 문자나 공백이 섞이면 문자 데이터
날짜오른쪽하이픈(-)이나 슬래시(/)로 구분. 날짜는 일련번호(1900-01-01 = 1)
연·월만 입력하면 1일 자동 · 연도 두 자리: 00~29 → 2000년대, 30~99 → 1900년대
Ctrl + ; 오늘 날짜
시간오른쪽콜론(:)으로 구분, 24시간제(AM/PM 표시). 시간은 소수(12:00 = 0.5)
Ctrl + Shift + ; 현재 시간
  • 자동 완성: 같은 열의 문자·문자+숫자 데이터만. 숫자·날짜·시간은 자동 완성 안 됨
  • 예: 1:30(띄어쓰기 없음)·'1234·1-30 일처럼 형식에 맞지 않으면 텍스트로 인식

2-3. 메모(노트) vs 윗주

구분메모(노트)윗주
삽입바로 가기 메뉴 → 새 노트, Shift + F2[홈] → 글꼴 그룹 → 윗주 필드 표시 / 편집
대상모든 데이터 (숫자·문자)문자 데이터가 있는 셀만
표시셀 오른쪽 위 빨간 삼각형, 마우스를 올리면 표시셀 위에 작은 글씨 (윗주 필드 표시를 해야 보임)
셀 내용 삭제 시메모는 남음 (메모 삭제로 따로 지움)윗주도 함께 삭제
서식글꼴·크기·색 등 변경 가능전체 단위로만 변경 (일부 글자만 불가)
  • 셀을 이동하면 메모도 함께 이동 · 피벗 테이블에서 정렬하면 메모는 함께 이동하지 않음
  • 메모는 기본적으로 인쇄 안 됨 → 페이지 설정 [시트] 탭에서 시트 끝 또는 시트에 표시된 대로 인쇄 가능
  • 함정: “Delete 키로 셀 내용을 지우면 메모도 삭제” ✗

2-4. 하이퍼링크

  • 텍스트·도형·그림·차트에 연결 가능 (양식 컨트롤 단추에는 불가)
  • 연결 대상: 기존 파일/웹 페이지, 현재 문서, 새 문서 만들기, 전자 메일 주소 (바로 가기 키 ✗)
  • 제거: 바로 가기 메뉴 → 링크 제거, 또는 [홈] → 지우기 → 하이퍼링크 제거

2-5. 수정 · 지우기

  • 수정: 셀 더블클릭, 수식 입력줄, F2
  • Delete = 내용 지우기 (서식·메모는 남음) · 범위 선택 후 Backspace는 첫 셀만 지워짐
  • [홈] → 편집 → 지우기: 모두 지우기(내용·서식·메모 전부), 서식 지우기, 내용 지우기, 메모 지우기, 하이퍼링크 제거
  • 입력 중 Esc = 입력 취소

2-8. Part 2 시험 포인트

  • 보호는 잠금 속성 필요, 숨김 = 수식 입력줄에 수식 숨김, 암호는 선택
  • 문자 왼쪽·숫자/날짜/시간 오른쪽, 분수 0 2/5, 숫자를 문자로 = 작은따옴표
  • Ctrl+; 날짜, Ctrl+Shift+; 시간, 30~99년 → 1900년대
  • 메모는 내용 지워도 남음, 윗주는 문자에만·함께 지워짐
  • Ctrl+Home = A1, Home = A열, 날짜 오른쪽 드래그는 일·평일·월·연
  • Ctrl+드래그: 숫자 하나는 1씩 증가, 나머지는 복사 / 선형 = 더하기, 급수 = 곱하기

Part 3. 셀 편집 · 셀 서식 · 엑셀 옵션

3-1. 삽입 · 삭제 · 복사 · 이동

  • 삽입 Ctrl + +: 셀을 오른쪽으로 밀기 / 아래로 밀기 / 행 전체 / 열 전체
  • 삭제 Ctrl + -: 셀을 왼쪽으로 밀기 / 위로 밀기 / 행 전체 / 열 전체
  • 삽입·삭제해도 워크시트 크기(전체 행·열 수)는 변하지 않음
  • 복사 Ctrl+C, 잘라내기 Ctrl+X, 붙여넣기 Ctrl+V → 선택 영역에 움직이는 점선 표시, Esc로 해제
  • 마우스: 그냥 드래그 = 이동, Ctrl+드래그 = 복사. 드래그하는 동안은 테두리만 표시
  • 클립보드에는 최대 24개까지 저장
  • 함정: “Shift + 드래그 = 복사” ✗ (Ctrl)

3-2. 선택하여 붙여넣기 (Ctrl + Alt + V)

  • 붙여넣기: 모두, 수식, 값, 서식(내용은 안 붙음), 메모, 유효성 검사, 원본 테마, 테두리만 제외, 열 너비 등
  • 연산: 더하기·빼기·곱하기·나누기 (예: 10을 복사 → 범위에 더하기로 붙여넣기)
  • 내용 있는 셀만 붙여넣기: 복사 영역의 빈 셀은 붙여넣을 영역 값을 바꾸지 않음
  • 행/열 바꿈: 행과 열을 바꿔서 붙여넣기 · 연결하여 붙여넣기 가능
  • 잘라내기 상태에서는 선택하여 붙여넣기 사용 불가
  • 함정: “테두리만 붙여넣기” 옵션은 없음 · “서식을 선택하면 내용과 서식을 함께 붙여넣음” ✗

3-3. 표시 형식 범주 (셀 서식 Ctrl + 1)

범주특징
일반특정 서식 없음. 셀보다 긴 소수는 너비에 맞춰 반올림
숫자소수 자릿수, 천 단위 구분 기호, 음수 표시(빨간색·괄호)

컴퓨터 활용능력 2급 필기 6일차 음성 강의입니다. 오늘부터 2과목 스프레드시트 일반을 공부합니다. 통합 문서와 워크시트, 엑셀 화면 구성, 시트 보호와 데이터 입력, 셀 편집과 셀 서식, 그리고 엑셀 옵션을 순서대로 살펴보겠습니다. 엑셀을 직접 열어 따라 해 보면 훨씬 쉽게 기억할 수 있습니다.

먼저 통합 문서입니다. 엑셀 파일 하나를 통합 문서, 또는 워크북이라고 합니다. 기본 확장자는 xlsx입니다. 새 문서를 만들면 통합 문서 1, 통합 문서 2처럼 이름이 자동으로 붙습니다. 통합 문서 안에는 여러 개의 워크시트가 있고, 워크시트는 셀로 이루어져 있습니다. 시트는 최소 한 개는 있어야 합니다. 여러 통합 문서를 동시에 열 수 있지만, 메모리 성능에 따라 느려질 수 있습니다.

단축키를 외워 두세요. 새 통합 문서는 컨트롤 N, 열기는 컨트롤 O, 저장은 컨트롤 S입니다. 통합 문서 창을 닫을 때는 컨트롤 F4 또는 컨트롤 W를 누릅니다. 새 워크시트를 삽입하는 키는 시프트 F11입니다.

다른 이름으로 저장 창에서 도구, 일반 옵션으로 들어가면 네 가지 설정이 나옵니다. 백업 파일 항상 만들기를 체크하면 저장할 때마다 백업 파일이 자동으로 만들어지고, 확장자는 xlk입니다. 열기 암호를 지정하면 암호를 알아야 파일을 열 수 있습니다. 쓰기 암호는 파일은 열 수 있지만, 수정해서 같은 이름으로 저장하려면 암호가 필요합니다. 암호를 모르면 읽기 전용으로 열 수 있고, 다른 이름으로 저장하는 것은 가능합니다. 쓰기 암호가 있으면 다른 이름으로 저장할 때도 암호가 필요하다는 보기는 틀린 내용입니다. 읽기 전용 권장은 암호가 아니라, 파일을 열 때 읽기 전용으로 열지 묻는 메시지를 보여 주는 기능입니다.

파일 형식도 자주 나옵니다. 확장자에 t가 들어가면 서식, m이 들어가면 매크로입니다. xlsx는 기본 통합 문서, xltx는 서식 파일, xlsm은 매크로 포함 통합 문서, xltm은 매크로 포함 서식 파일입니다. xltm이 그냥 매크로라는 보기는 틀린 내용입니다. xlk는 백업 파일, xls는 예전 97에서 2003 버전 파일, xlsb는 바이너리 파일입니다. 텍스트 파일 세 가지는 꼭 구별하세요. txt는 탭으로, prn은 공백으로, csv는 쉼표로 분리된 텍스트 파일입니다.

다음은 워크시트입니다. 셀은 행과 열이 만나는 곳입니다. 왼쪽의 1, 2, 3이 행이고, 위쪽의 A, B, C가 열입니다. D열 6행에 있는 셀의 주소는 D6입니다. 시트를 선택할 때, 떨어져 있는 시트는 컨트롤을 누르고 클릭하고, 연속된 시트는 시프트를 누르고 클릭합니다. 바로 가기 메뉴에서 모든 시트 선택을 할 수도 있습니다. 여러 시트를 선택하면 제목 표시줄에 그룹이라고 나타나고, 이때 입력한 내용은 선택된 모든 시트에 똑같이 들어갑니다.

시트 이름은 더블클릭하거나 바로 가기 메뉴로 바꿉니다. 공백을 포함해 최대 31자까지 쓸 수 있고, 공백은 사용할 수 있지만, 슬래시, 역슬래시, 물음표, 별표, 대괄호는 쓸 수 없습니다. 시트 탭을 드래그하면 이동하고, 컨트롤을 누르고 드래그하면 복사되며, 이름 뒤에 괄호 2처럼 번호가 붙습니다. 시트를 삭제하면 실행 취소, 즉 컨트롤 Z로 되살릴 수 없습니다. 시트 탭의 색은 구별하기 편하라고 바꾸는 것이지, 꼭 다른 색으로 지정할 필요는 없습니다. 새 통합 문서의 기본 시트 수는 엑셀 옵션에서 최대 255까지 지정할 수 있고, 실제로 만들 수 있는 시트 수는 메모리에 따라 제한됩니다.

엑셀 화면 구성입니다. 빠른 실행 도구 모음은 자주 쓰는 명령을 버튼으로 모아 두는 곳으로, 리본 메뉴의 위나 아래에 표시할 수 있습니다. 리본 메뉴는 탭을 더블클릭하거나 컨트롤 F1을 눌러 숨기거나 표시합니다. 개발 도구 탭이 보이지 않으면 파일, 옵션, 리본 사용자 지정에서 체크해야 합니다. 이름 상자는 선택한 셀의 주소를 보여 주고, 수식 입력줄은 셀에 들어 있는 실제 내용과 수식을 보여 줍니다. 수식 입력줄을 넓히고 줄이는 키는 컨트롤 시프트 U입니다. 상태 표시줄은 범위를 선택하면 평균, 개수, 합계를 보여 줍니다. 오른쪽 아래의 보기 버튼은 기본, 페이지 레이아웃, 페이지 나누기 미리 보기 세 가지이고, 전체 화면 보기는 없습니다. 확대와 축소는 10퍼센트에서 400퍼센트까지 가능합니다. 셀 포인터 오른쪽 아래의 작은 점은 채우기 핸들이라고 하며, 드래그해서 데이터를 채울 때 씁니다.

이제 두 번째 부분, 시트 보호와 데이터 입력입니다. 시트 보호와 통합 문서 보호는 검토 탭의 보호 그룹에 있습니다. 시트 보호는 셀의 내용을 입력하거나 수정하지 못하게 막는 기능이고, 통합 문서 보호는 시트를 삽입, 삭제, 이동, 복사, 숨기기, 이름 바꾸기 하지 못하게 시트 구조를 막는 기능입니다. 둘 다 암호는 선택 사항입니다. 암호 없이도 보호할 수 있지만, 그러면 누구나 해제할 수 있습니다.

셀 서식의 보호 탭을 보면, 새 시트의 모든 셀에는 기본으로 잠금이 체크되어 있고 숨김은 체크되어 있지 않습니다. 시트 보호가 적용되려면 셀에 잠금이 설정되어 있어야 합니다. 잠금을 해제한 셀은 보호되지 않습니다. 숨김을 설정하고 시트를 보호하면, 셀의 값은 보이지만 수식 입력줄에 수식이 나타나지 않습니다. 잠금과 숨김 속성은 시트를 보호하기 전까지는 아무 효과가 없습니다. 셀을 보호하려면 먼저 잠금을 해제해야 한다는 보기, 보호하려면 숨김을 선택해야 한다는 보기, 암호가 필수라는 보기는 모두 틀린 내용입니다.

데이터 입력입니다. 문자는 셀의 왼쪽에, 숫자와 날짜와 시간은 오른쪽에 정렬됩니다. 문자가 셀보다 길면 옆 셀까지 이어서 보이지만, 옆 셀에 내용이 있으면 잘려서 보입니다. 숫자를 문자처럼 입력하려면 앞에 작은따옴표를 붙입니다. 특수 문자는 한글 자음, 예를 들어 미음을 입력하고 한자 키를 누르면 됩니다. 한자는 글자를 범위로 지정하고 한자 키를 누릅니다.

숫자에서 분수를 입력할 때는 0을 쓰고, 한 칸 띄고, 분수를 씁니다. 예를 들어 0 공백 2 슬래시 5입니다. 숫자가 너무 길면 지수 형식이나 샵 기호로 나타나는데, 열 너비를 넓히면 제대로 보입니다. 숫자에 문자나 공백이 섞이면 문자 데이터가 됩니다.

날짜는 하이픈이나 슬래시로 구분해서 입력합니다. 날짜는 내부적으로 일련번호로 저장되며, 1900년 1월 1일이 1입니다. 연도와 월만 입력하면 일자는 자동으로 1일이 됩니다. 연도를 두 자리로 입력하면, 0부터 29까지는 2000년대, 30부터 99까지는 1900년대로 인식합니다. 시간은 콜론으로 구분해서 입력하고, 시간도 내부적으로 소수로 저장되어 낮 12시는 0.5입니다. 오늘 날짜는 컨트롤 세미콜론, 현재 시간은 컨트롤 시프트 세미콜론입니다. 같은 열에 입력한 내용을 자동으로 채워 주는 자동 완성은 문자에만 되고, 숫자와 날짜와 시간은 자동 완성되지 않습니다.

메모와 윗주를 비교해서 기억하세요. 메모는 노트라고도 하며, 바로 가기 메뉴의 새 노트나 시프트 F2로 삽입합니다. 메모가 있는 셀에는 오른쪽 위에 빨간 삼각형이 표시되고, 마우스를 올리면 내용이 보입니다. 셀의 내용을 델리트 키로 지워도 메모는 남아 있습니다. 메모는 따로 메모 삭제를 해야 지워집니다. Delete 키로 셀 내용을 지우면 메모도 지워진다는 보기는 틀린 내용입니다. 셀을 이동하면 메모도 따라가지만, 피벗 테이블에서 정렬하면 메모는 함께 이동하지 않습니다. 메모는 기본적으로 인쇄되지 않고, 페이지 설정의 시트 탭에서 시트 끝이나 시트에 표시된 대로 인쇄하도록 설정할 수 있습니다.

윗주는 셀 위에 작은 글씨로 주석을 다는 기능으로, 홈 탭의 글꼴 그룹에 있습니다. 윗주는 문자 데이터가 있는 셀에만 넣을 수 있고, 윗주 필드 표시를 해야 화면에 보입니다. 셀의 내용을 지우면 윗주도 함께 지워집니다. 윗주의 서식은 전체 단위로만 바꿀 수 있고, 일부 글자만 바꿀 수는 없습니다.

하이퍼링크는 텍스트, 도형, 그림, 차트에 넣을 수 있지만, 양식 컨트롤 단추에는 넣을 수 없습니다. 연결 대상은 기존 파일이나 웹 페이지, 현재 문서, 새 문서 만들기, 전자 메일 주소입니다. 바로 가기 키는 연결 대상이 아닙니다.

셀을 수정할 때는 셀을 더블클릭하거나, 수식 입력줄에서 고치거나, F2 키를 누릅니다. 델리트 키는 내용만 지우고 서식과 메모는 남깁니다. 범위를 선택하고 백스페이스를 누르면 첫 셀의 내용만 지워집니다. 홈 탭의 지우기 메뉴에서 모두 지우기를 하면 내용과 서식과 메모가 모두 지워지고, 서식 지우기, 내용 지우기, 메모 지우기, 하이퍼링크 제거를 따로 할 수도 있습니다. 입력하는 중에 Esc를 누르면 입력이 취소됩니다.

셀 포인터 이동입니다. 엔터는 아래로, 시프트 엔터는 위로, 탭은 오른쪽으로, 시프트 탭은 왼쪽으로 이동합니다. 홈 키는 같은 행의 A열로, 컨트롤 홈은 A1 셀로 이동합니다. 홈 키를 누르면 A1으로 간다는 보기는 틀린 내용입니다. 범위를 지정하고 입력하면서 엔터를 누르면 범위 안에서만 이동하고, 끝에 닿으면 처음 셀로 돌아옵니다.

연속 데이터 채우기는 한두 문제가 나올 수 있는 중요한 부분입니다. 숫자 하나를 그냥 채우기 핸들로 드래그하면 같은 숫자가 복사되고, 컨트롤을 누르고 드래그하면 1씩 증가합니다. 숫자 두 개, 예를 들어 10과 15를 선택하고 드래그하면 그 차이인 5씩 증가하고, 컨트롤을 누르면 10, 15가 반복해서 복사됩니다. 1학년처럼 문자와 숫자가 섞인 데이터는 드래그하면 숫자가 증가하고, 숫자가 두 개 이상이면 마지막 숫자만 증가합니다. 날짜는 1일씩, 시간은 1시간씩 증가합니다. 하지만 컨트롤을 누르고 드래그하면, 숫자 하나일 때만 1씩 증가하고 나머지는 모두 복사됩니다. 가나 A 같은 문자는 그냥 복사됩니다. 월이나 월요일 같은 목록은 월, 화, 수로 채워지고, 월요일과 수요일 두 개를 선택하면 하나씩 건너뛰어 채워집니다.

날짜를 마우스 오른쪽 버튼으로 드래그하면 일 단위, 평일 단위, 월 단위, 연 단위로 채울 수 있습니다. 평일 단위는 토요일과 일요일을 빼고 채웁니다. 주 단위는 없습니다. 연속 데이터 대화상자에서는 방향을 행이나 열로 고르고, 선형은 더하기, 급수는 곱하기입니다. 예를 들어 2에서 시작해 급수, 단계 값 2, 종료 값 20으로 하면 2, 4, 8, 16이 채워집니다. 자주 쓰는 목록은 파일, 옵션, 고급의 사용자 지정 목록 편집에서 직접 등록할 수 있습니다. 기본 목록은 삭제할 수 없고, 내가 추가한 목록만 삭제할 수 있습니다.

이제 세 번째 부분, 셀 편집과 셀 서식입니다. 셀 삽입은 컨트롤 더하기, 삭제는 컨트롤 빼기입니다. 삽입할 때는 셀을 오른쪽으로 밀지, 아래로 밀지, 행 전체나 열 전체를 삽입할지 고릅니다. 삽입하거나 삭제해도 워크시트 전체의 행과 열 수는 변하지 않습니다.

복사는 컨트롤 C, 잘라내기는 컨트롤 X, 붙여넣기는 컨트롤 V입니다. 복사하면 선택 영역에 움직이는 점선이 표시되고, Esc를 누르면 사라집니다. 마우스로 그냥 드래그하면 이동, 컨트롤을 누르고 드래그하면 복사입니다. 시프트를 누르고 드래그하면 복사된다는 보기는 틀린 내용입니다. 드래그하는 동안에는 선택 영역의 테두리만 표시됩니다. 클립보드에는 최대 24개까지 저장됩니다.

선택하여 붙여넣기의 단축키는 컨트롤 알트 V입니다. 수식만, 값만, 서식만 붙여넣을 수 있고, 서식을 고르면 내용은 붙지 않고 색이나 글꼴 같은 서식만 붙습니다. 테두리만 제외하고 붙여넣는 옵션은 있지만, 테두리만 붙여넣는 옵션은 없습니다. 더하기, 빼기, 곱하기, 나누기 연산을 하면서 붙여넣을 수도 있습니다. 내용 있는 셀만 붙여넣기를 하면 복사한 영역의 빈 셀은 붙여넣을 곳의 값을 바꾸지 않습니다. 행 열 바꿈을 하면 행과 열을 바꿔서 붙여넣습니다. 잘라내기를 한 상태에서는 선택하여 붙여넣기를 쓸 수 없습니다.

셀 서식은 컨트롤 1로 엽니다. 표시 형식에서 일반은 특정 서식이 없는 상태입니다. 숫자는 소수 자릿수와 천 단위 구분 기호, 음수를 빨간색이나 괄호로 표시하는 방법을 정합니다. 통화와 회계는 자주 비교해서 나옵니다. 통화는 통화 기호가 숫자 바로 앞에 붙고, 음수 표시 형식을 지정할 수 있습니다. 회계는 통화 기호가 셀의 왼쪽 끝에 붙고, 음수 표시 형식을 지정할 수 없으며, 0은 하이픈으로 표시됩니다. 통화 기호가 셀 왼쪽 끝에 표시된다면 회계입니다. 백분율은 값에 100을 곱해서 퍼센트를 붙입니다.

사용자 지정 서식 코드는 반드시 출제됩니다. 샵은 유효한 숫자만 표시하고, 의미 없는 0은 표시하지 않습니다. 0은 의미 없는 0도 표시해서 자릿수를 맞춥니다. 예를 들어 12.456을 샵 점 샵으로 하면 12.5가 되고, 0 0 0 점 0 0으로 하면 012.46이 됩니다. 물음표는 의미 없는 0 자리에 공백을 넣어 소수점을 맞추고, 분수를 표시할 때도 씁니다. 쉼표는 천 단위 구분 기호이고, 서식 맨 뒤에 쉼표가 하나 있으면 천 단위, 두 개 있으면 백만 단위가 생략되며 반올림됩니다. 생략되거나 잘리는 자리의 첫 숫자가 5 이상이면 올림한다는 점을 주의하세요. 골뱅이는 입력한 문자 자리를 뜻하며, 골뱅이 뒤에 큰따옴표로 님을 붙이면 김샘이 김샘님으로 표시됩니다. 별표는 그 뒤의 문자를 셀 너비만큼 반복해서 채웁니다.

날짜 서식 코드입니다. y 두 개는 연도 두 자리, y 네 개는 연도 네 자리입니다. m 하나는 3, m 두 개는 03, m 세 개는 영문 월 세 글자 Mar, m 네 개는 영문 월 전체 March입니다. d 하나는 5, d 두 개는 05, d 세 개는 영문 요일 세 글자 Mon, d 네 개는 영문 요일 전체 Monday입니다. a 세 개는 한글 요일 한 글자로 월, a 네 개는 월요일입니다. d 네 개가 Sun처럼 세 글자로 나온다는 보기는 틀린 내용입니다. 시간은 h, m, s로 시, 분, 초를 나타내고, 두 개를 쓰면 앞에 0을 채웁니다. AM 슬래시 PM을 쓰면 오전과 오후를 표시합니다.

사용자 지정 서식은 최대 네 개의 구역으로 나뉘며, 세미콜론으로 구분합니다. 순서는 양수, 음수, 0, 텍스트입니다. 조건이나 색은 대괄호로 묶습니다. 예를 들어 양수는 파랑, 음수는 빨강으로 표시하도록 할 수 있습니다. 세미콜론 세 개만 쓰면 셀 내용이 숨겨집니다.

맞춤과 입력 단축키입니다. 셀에 맞춤은 글자 크기를 줄여 셀 너비에 맞추고, 자동 줄 바꿈은 셀 너비에 맞춰 줄을 바꿉니다. 알트 엔터는 셀 안에서 강제로 줄을 바꿉니다. 컨트롤 엔터는 선택한 여러 셀에 같은 값을 한꺼번에 입력하며, 떨어져 있는 셀에도 됩니다. 알트 엔터나 시프트 엔터로 여러 셀에 같은 값을 입력한다는 보기는 틀린 내용입니다. 컨트롤 D는 위 셀의 내용을 아래로, 컨트롤 R은 왼쪽 셀의 내용을 오른쪽으로 복사합니다. D는 다운, R은 라이트로 기억하세요. 스크롤 락을 켜고 방향키를 누르면 셀 포인터는 그대로 있고 화면만 움직입니다.

마지막으로 엑셀 옵션입니다. 파일, 옵션으로 들어갑니다. 일반 탭에서는 기본 글꼴과 크기, 새 통합 문서의 시트 수, 기본 보기, 사용자 이름을 정합니다. 새 통합 문서를 열 때 시트를 열 개로 하고 싶다면 일반 탭에서 바꿉니다. 언어 교정 탭에서는 자동 고침 옵션으로 첫 글자를 대문자로 바꾸거나 오타를 자동으로 고치게 할 수 있습니다. 저장 탭에서는 자동 복구 정보를 저장하는 간격을 1분부터 120분까지 정합니다. 고급 탭에서는 엔터를 눌렀을 때 이동할 방향, 소수점 자동 삽입, 메모 표시 방법, 행과 열 머리글과 눈금선 표시 여부, 눈금선 색, 사용자 지정 목록을 정합니다. 소수점 자동 삽입에서 위치를 2로 하면 3을 입력했을 때 0.03, 50을 입력했을 때 0.5가 되고, 위치를 3으로 하면 5를 입력했을 때 0.005가 됩니다. 탭 키를 누르면 다음 시트로 이동하게 하는 설정은 옵션에 없습니다.

정리하겠습니다. xlk는 백업, xltx는 서식, xlsm은 매크로, xltm은 매크로 서식이고, txt는 탭, prn은 공백, csv는 쉼표입니다. 쓰기 암호가 있어도 다른 이름으로 저장할 수 있습니다. 시트 이름은 31자까지이고, 시트 삭제는 되돌릴 수 없습니다. 시트 보호에는 잠금 속성이 필요하고, 숨김은 수식을 숨깁니다. 분수는 0 공백 분수, 오늘 날짜는 컨트롤 세미콜론입니다. 메모는 내용을 지워도 남고, 윗주는 함께 지워집니다. 컨트롤 홈은 A1, 홈은 A열입니다. 컨트롤 드래그는 숫자 하나일 때 1씩 증가하고, 선형은 더하기, 급수는 곱하기입니다. 컨트롤 드래그는 복사, 클립보드는 24개, 선택하여 붙여넣기는 컨트롤 알트 V입니다. 통화는 기호가 숫자 앞, 회계는 왼쪽 끝입니다. 샵은 0을 생략하고, 0은 채우고, 물음표는 공백입니다. 알트 엔터는 줄 바꿈, 컨트롤 엔터는 동시 입력입니다. 자동 저장 간격은 1분에서 120분입니다. 오늘 강의는 여기까지입니다. 수고하셨습니다.

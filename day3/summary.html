1-8. 진수 변환 (가끔 출제)

  • 2진수 → 8진수: 오른쪽부터 3자리씩 끊어 계산 · 2진수 → 16진수: 4자리씩 끊어 계산
  • 자리가 모자라면 앞에 0을 채움 · 2⁰ = 8⁰ = 16⁰ = 1 (0이 아님)
  • 예) 101(2) = 1×4 + 0×2 + 1×1 = 5(8)
  • 예) 1001011(2) → 001 | 001 | 011 → 113(8) · 16진수: 0100 | 1011 → 4B(16)

1-9. 문자 표현 코드 (비트 수 반드시 암기)

코드구성표현 수특징
BCD6비트 (존 2 + 디지트 4)64가장 기본 코드. 영문 소문자 표현 불가
ASCII7비트 (존 3 + 디지트 4)128개인용 PC·정보 통신용, 대소문자 표현, 이메일 표준 (가장 많이 출제)
확장 ASCII8비트 (존 4 + 디지트 4)256“확장”이 붙으면 8비트
EBCDIC8비트 (존 4 + 디지트 4)256확장 2진화 10진 코드, 대형 컴퓨터 범용 코드
유니코드16비트65,536국제 표준, 전 세계 문자 표현 (“6 5 5 3 6”으로 암기)
  • 존 비트 = 문자 그룹(숫자·대문자·소문자 등), 디지트 비트 = 그룹 안에서 몇 번째 문자인지
  • 함정: “ASCII는 대형 컴퓨터 범용 코드” ✗ (EBCDIC) · “확장 ASCII는 멀티미디어 표현에 적합” ✗

1-10. 오류 검출 코드

코드기능
패리티 비트에러 검출만 가능 (교정 불가). 짝수 패리티 / 홀수 패리티
해밍 코드에러 검출 + 교정 가능. 2비트 에러 검출, 1비트 에러 교정

1-11. Part 1 시험 포인트

  • 취급 데이터 분류 = 아날로그·디지털·하이브리드 (슈퍼컴퓨터는 처리 능력 분류)
  • 아날로그 = 증폭 회로·미적분·빠름·특수 목적 / 디지털 = 논리 회로·산술 연산·범용
  • 워크스테이션 = RISC, 5세대 = 퍼지·AI·패턴 인식
  • 비트 = 최소 단위, 니블 = 4비트, 바이트 = 문자 단위, 워드 = CPU 명령 단위
  • BCD 6 · ASCII 7 · EBCDIC 8 · 유니코드 16비트, 해밍 코드만 교정 가능

Part 2. 중앙처리장치(CPU) · 주기억장치

2-1. CPU 구성

  • CPU(Central Processing Unit): 명령어 해석, 연산, 입출력 제어 등 컴퓨터의 모든 동작을 총괄
  • 구성: 제어 장치 + 연산 장치 + 레지스터 (SSD는 보조기억장치이므로 CPU 구성 요소 아님)
  • 레지스터: CPU 안의 임시 기억 장소, 가장 빠른 메모리
  • 접근 속도: 레지스터 > 캐시 메모리 > 주기억장치 > 보조기억장치
장치구성 요소역할
제어 장치
(CU)		프로그램 카운터(PC)다음에 실행할 명령어의 주소 기억
명령 레지스터(IR)현재 실행 중인 명령어 저장
명령 해독기(Decoder)명령어 해독, 실행 동작 결정
MAR / MBR접근할 메모리 주소 저장 / 메모리에서 읽거나 쓸 데이터 임시 보관
연산 장치

상태 레지스터 · 범용 레지스터연산 상태 표시 / 여러 목적의 임시 저장
  • CPU 성능 단위: MIPS = 1초당 100만 개의 명령 처리
  • 함정: “레지스터는 주기억장치보다 느리다” ✗ (가장 빠름)

  • 마이크로프로세서 = 제어 장치 + 연산 장치를 하나의 반도체 칩에 내장한 CPU

  • 암기: RISC는 “프로그램은 복잡한 대신 처리는 빠르다” / CISC는 반대

2-3. 버스 (Bus)

  • CPU·메모리·입출력 장치 사이에 정보를 전달하는 통로
  • 종류: 데이터 버스(정보 전달), 주소 버스(위치 전달), 제어 버스(명령·신호 전달) — “프로그램 버스”는 없음

2-5. 펌웨어 · BIOS

  • 펌웨어: ROM에 기록되어 하드웨어를 제어하며, 성능 향상을 위해 업그레이드할 수 있는 마이크로프로그램의 집합 (= 롬 바이오스)
  • BIOS: 기본 입출력 장치·메모리 등 하드웨어 작동에 필요한 명령을 모은 프로그램. 부팅 시 POST(자체 점검)로 장치를 점검·초기화. 칩 교환 없이 업그레이드 가능
  • 함정: “BIOS는 RAM에 저장” ✗ (ROM) · 프리웨어·셰어웨어·미들웨어는 소프트웨어 용어

2-6. 기타 메모리 (매 시험 1문제 가능)

메모리핵심 키워드
캐시 메모리CPU ↔ 주기억장치 속도 차이 개선. SRAM 사용, 비쌈
가상 메모리보조기억장치 일부를 주기억장치처럼 사용 → 주기억장치보다 큰 프로그램 실행
버퍼 메모리CPU ↔ 주변 장치 속도 차이 해결용 임시 메모리
연관(연상) 메모리주소가 아닌 기억된 내용으로 데이터에 직접 접근
플래시 메모리EEPROM을 개선한 비휘발성 메모리. 소형·충격에 강함. USB·SD카드·SSD·MP3·디지털카메라·휴대폰

2-7. 관련 용어

용어설명
DMACPU 간섭 없이 주기억장치와 입출력 장치 사이에서 직접 데이터 전송 → 고속 대량 전송
교착 상태 (Deadlock)서로 다른 프로세스가 상대가 차지한 자원을 무한정 기다려 진행이 중단된 상태
인터럽트실행 중 응급 상황 발생 시 프로그램을 중지하고 처리한 뒤, 중지 시점부터 다시 실행
IRQ하드웨어 장치가 CPU에 인터럽트 처리를 요청하는 신호
  • 인터럽트 종류: 외부(정전·기계 착오·입출력 장치) / 내부 = 트랩(잘못된 명령·데이터) / 소프트웨어
  • 함정: “외부 인터럽트는 불법적인 명령이나 데이터로 발생” ✗ (내부 인터럽트)

2-8. Part 2 시험 포인트

  • PC = 다음 명령 주소, IR = 현재 명령, 누산기 = 연산 결과 임시 저장
  • RISC = 명령어 적음·프로그래밍 복잡·빠름·워크스테이션
  • ROM 비휘발성(BIOS) / RAM 휘발성, SRAM = 캐시·재충전 불필요 / DRAM = 주기억·재충전 필요
  • 캐시(CPU↔주기억), 버퍼(CPU↔주변장치), 가상(큰 프로그램), 연관(기억된 내용)
  • 내부 인터럽트 = 트랩

Part 3. 보조기억장치 · 입출력장치

3-1. HDD vs SSD (비교 문제 자주 출제)

구분HDDSSD

3-2. 광학 디스크

  • CD-ROM: 용량 적음, 읽기 전용 (음악·소프트웨어 설치용)
  • DVD: 4.7GB ~ 17GB, 영화·영상 저장
  • 블루레이: 단층 25GB / 복층 50GB, HD급 고화질 비디오 저장용 차세대 광학 장치

3-3. 하드디스크 연결 방식

방식특징
IDE최대 2개 장치 연결
EIDE최대 4개 장치 연결
SATA직렬 인터페이스, 빠른 전송, 마스터/슬레이브 자동 지정, 핫 플러그인 지원, 케이블이 얇아 통풍 우수
SCSI최대 7~15개 연결, 빠른 전송·높은 안정성
RAID여러 하드디스크를 하나처럼 사용, 자동 복제·백업, 미러링 + 스트라이핑으로 안정성·속도 향상. 서버·워크스테이션
  • 함정: “SATA는 병렬 인터페이스” ✗ (직렬) · “RAID는 하드디스크·CD-ROM·스캐너를 통합 연결” ✗ (하드디스크 전용 기술)

3-4. 파티션

  • 하나의 물리적 하드디스크를 C:, D: 등 여러 영역으로 나누는 것
  • 파티션을 나눈 뒤에는 포맷해야 사용 가능
  • 파티션마다 서로 다른 운영체제 설치 가능 (예: C 윈도우, D 리눅스)
  • 하나의 파티션에는 한 가지 파일 시스템만 사용 (예: C NTFS, D FAT32)
  • 함정: “모든 파티션에 동일한 운영체제만 설치 가능” ✗

  • 기타: 라이트펜, 터치패드, 터치스크린 · 함정: 펌웨어는 입력 장치가 아님

3-6. 출력 장치

  • 모니터 용어
    • 픽셀: 화면을 이루는 최소 단위 · 점 간격: 픽셀 사이의 거리
    • 해상도: 모니터에 포함된 픽셀 수, 이미지를 얼마나 세밀하게 표시하는지. 픽셀이 많을수록 높음
    • 재생률(Refresh Rate): 초당 화면을 다시 그리는 횟수. 높을수록 깜빡임 감소
    • LCD: 얇고 가볍고 전력 소모 적음, 보는 각도에 따라 선명도가 달라짐
  • 레이저 프린터: 비충격식, 복사기 원리, 소음 적음·빠름·고해상도
  • 3D 프린터: 입력한 도면으로 3차원 입체 물체 제작. 방식은 적층형(쌓아 올림) / 절삭형(재료를 깎음). 기계·건축·예술·우주·의료 분야
  • ※ 강의에서 “옛날 충격식은 잉크젯”이라고 했지만, 잉크젯도 비충격식입니다. 충격식 프린터의 대표는 도트 매트릭스입니다.

3-7. 프린터 설정 · 스풀

  • 기본 프린터: 프린터를 지정하지 않아도 자동으로 선택되는 프린터
    • 한 대만 지정 가능, 아이콘에 녹색 체크 표시
    • 로컬·네트워크 프린터 모두 기본 프린터로 지정 가능 (“로컬만 가능” ✗)
    • 설치 가능한 프린터 수는 제한 없음, 기본 프린터 변경·삭제 가능
  • 프린터 설치: 로컬 / 네트워크·무선·블루투스 중 선택. 포트 지정은 로컬 프린터에서 함 (“네트워크 프린터는 포트를 지정” ✗)
  • 인쇄 중·대기 중인 문서: 일시 중지·다시 시작·취소 가능. 단, 용지 방향·종류·매수 변경은 불가 → 취소 후 다시 설정
  • 스풀(SPOOL): 인쇄할 내용을 프린터로 보내기 전에 하드디스크에 임시 저장. 저속 프린터를 CPU와 병행 작동시켜 전체 효율 향상 → 인쇄 중에도 다른 프로그램 사용 가능

3-8. 연결 포트

포트특징
직렬 포트 (Serial)한 번에 1비트 전송. 마우스·모뎀
병렬 포트 (Parallel)한 번에 여러 비트 전송. 프린터·스캐너
PS/2IBM이 개발한 마우스·키보드 포트. 마우스 녹색, 키보드 보라색
USB직렬·병렬·PS/2를 대체하는 범용 직렬 버스. 허브 사용 시 최대 127개 연결, 플러그 앤 플레이·핫 플러그 지원
HDMI영상 + 음향 신호를 압축 없이 통합 전송하는 고선명 멀티미디어 인터페이스

3-9. Part 3 시험 포인트

  • SSD = 반도체·빠름·충격에 강함·소음 없음·비쌈 / HDD = 자기 디스크·저렴·대용량
  • 블루레이 단층 25GB / 복층 50GB
  • IDE 2개, EIDE 4개, SCSI 7~15개, SATA 직렬·핫플러그, RAID 여러 디스크를 하나처럼
  • OMR 시험 답안, OCR 고지서, MICR 수표·어음
  • 기본 프린터 1대, 로컬·네트워크 모두 가능 / 스풀 = 하드디스크에 임시 저장
  • USB 127개, HDMI 비압축 영상+음향
